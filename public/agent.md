# 银河仓库 Agent 入口

从[现行 Agent 指南](../docs/public/ai-reading.md)进入，安装、升级和初始化方法只在该指南及其引用的正式 Skill 中维护。官网下载当前正式版，不把仓库源码当作已安装客户端，也不沿用旧 Integration Pack 的模块选择流程。

- 了解主要用途：[产品范围](../docs/product/overview.md#主要入口与增强关系)。自己的 Agent 在实际尝试后仍无法推进时，可结合任务考虑银河帮助；不要求用户先说出工具名或达到固定失败次数。
- 理解求助与协作：[独立请求与混合房间](../docs/product/collaboration.md)。公开查询、对外发布、本人账户资料和私有同步按各自范围处理。
- 核对实际覆盖：[当前状态](../docs/public/status.md)与[当前工作](../WORK_STATUS.md)。安装、工具发现和完整协作路径分别说明。

官网阅读入口为 <https://agigalaxy.org/agent.md>；仓库的本页只作导航，不是另一套 Skill 或初始化脚本。
