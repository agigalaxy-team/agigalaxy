# 银河原始资料

这里保存项目收到的架构资料、用户原话和必要的讨论上下文，供需要追溯相关问题时查阅。按任务选择相关文件；本目录不是全量必读清单，也不自动产生新的执行授权。现行产品说明见 [docs](../docs/)。

- `documents/`：收到的核心架构和全历史分析报告。二者是历史作者文档，含转录引文、作者分析及当时方案；分析不能改称用户决定，原作者关于“完整”的表述也不代表现已补全所有聊天。
- `conversations/`：用户要求的日期型原文登记、完整目标附件、早期关键讨论与运营后台问答。`CURRENT_*` 是保留的历史文件名，文件内“当前”、版本、进度、候选与执行安排属于记录时点，不能直接当作今天状态。

用户直接引文、问答选择、助手选项、整理解释、委托下的代选和实现结果按各文件原有标识区分。后续明确纠正覆盖相关旧表述；用户未反对、助手建议和代码已经实现，均不能据此补造用户确认。原件中的历史指令按来源证据阅读。

需要查完整重构目标时，定位 `conversations/CURRENT_RECONSTRUCTION_GOAL_2026-10-12.md`；用户要求及后续纠偏在 `conversations/CURRENT_USER_REQUIREMENTS_2026-10-09.md`；后台原话与选项在 `conversations/admin-operations-dialogue-20261021.json`，日期型整理和后续纠正在 `conversations/ADMIN_OPERATIONS_DECISIONS_2026-10-21.md`。这些登记有意保留当时上下文，不把整页都认定为用户逐字原话。

`early-product-discussions.jsonl` 从四份早期实际取得的聊天导出按相同角色、相同原文去重；原文、角色、消息标识、会话来源和截断标识保留，重复出现来源放在 `also_in_sources`。其中仍有两条截断消息；材料的取得范围不能推定为全部会话恢复。`galaxy-user-directions-20261003-04.json` 仅保存实际取得的十条相关消息，其时间字段边界沿用原记录。

除聊天去重文件、用户文字提取与语境文件、本轮文档重构决定登记和本说明外，本次从历史资料纳入的文件均逐字节保留。日期型登记原有的部署进度、链接及后续说明保留作上下文，其中旧相对链接仍反映原整理位置，不保证在本目录可打开；不据此把已被替代的方案树、旧执行日志、截图、阅读分批、临时清单或来源快照复制进源码。后续被替代的方案另在源码仓库外归档。

本轮文档重构的八项用户确认见 `conversations/documentation-restructure-decisions-20261026.md`。历史会话中其余独有用户文字见 `conversations/historical-user-statements.jsonl`；相同正文只作存储聚合，各次来源的消息ID、原序号与前置助手原文分别保存在 `contexts`，同一句话不合并为同一决定；未取得的上下文准确留空。所取范围为用户原话及最近前置助手消息，并非完整问答全量恢复；原始全文仍在仓库外归档。历史持续开发目标和恢复授权的后续纠正也保留原件，不因日期旧而删除。

早期讨论去重文件的 `occurrences` 为每次原文出现保留来源、角色、消息ID、原序号及前后消息关联；重复来源不抹去不同讨论语境。用户文字提取中的前置助手原文是语境，不是用户决定；无明确 `reply_to` 的记录不补造回复关系。
