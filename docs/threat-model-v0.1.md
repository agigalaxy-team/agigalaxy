| ID / 威胁 | 已有控制 | 剩余边界 |
|---|---|---|
| T01 密钥接管 | 用途限定签名、独立信任根/撤销与事故暂停恢复；integration实际非root身份和密钥分离已验证 | 公开根独立分发、真实泄露场景和运营恢复责任仍待落实 |
| T02 恶意Manifest | 严格schema/版本/签名、外部pin、序号防回退和过期拒绝；发现不自动授权 | 正式发行/初始根分发和真实宿主信任确认待落实 |
| T03 重放 | 旧挑战一次消费与事务幂等；OIDC登录与可选OAuth资源入口独立校验，不能回退尝试其他令牌 | 真实AS配置、第三方客户端及正式认证服务运行仍待验收 |
| T04 跨主体授权 | 事务内重查binding/credential/Consent；搜索候选、导出、Profile、Honor和Context继续按当前受众/来源过滤 | 真实宿主跨用户流程及外部副本不能以单元证据代替 |
| T05 恶意证据URL | 共享公网HTTPS限制、固定解析地址、重定向/大小/超时与取消；仅允许受约束来源适配器 | 新增来源须明确注册和验证；未提供任意远程代码适配器 |
| T06 伪造验证/来源自证 | CI明确有限来源强度；参与者验证声明、Case纠正和独立角色复核分别存储，Proof读时重新核对 | 声明验证不证明独立性；真实任务效果、外部证据与独立验证者仍需人工/业务验收 |
| T07 关联方互证 | 当前可见范围发现声明关联方、重复来源、互相接受环与集中参与；输出复核提示，不自动惩罚或授予能力 | 不能推断隐蔽共同控制者或串谋；未扫描不可见材料，运营争议处理仍需责任人 |
| T08 内容滥用 | 敏感字段政策、精确预览和脱敏日志；Case/自述/资格举报、隔离、补证与申诉已接入追加处置 | 自由文本不能保证自动识别全部秘密或滥用；公开运营审核/处理时限仍未指定 |
| T09 资源耗尽 | 分类限额、事务资源预算、有限作业重试/停止和监控规则；目标机器负载已有实测 | 仍为单进程请求计数；完整生产拓扑/费用预算和长期容量未验收 |
| T10 信任材料提示注入 | 权限仍由确定性代码和精确Consent检查，外部文本/历史/能力声明均不是控制指令 | 未实现自主AI评估器；没有证明任意外部模型在端到端场景均能抵抗提示注入 |
| T11 过期离线状态 | 来源周期重验、授权依赖失效、搜索触发器与有界新鲜度、原生过期/撤销展示已实现 | 外部源变化须被观察；在途响应、已下载副本和跨实例正式时限仍有限制 |
