# 数据、身份与使用范围

[文档目录](README.md) · [项目概览](project-overview.md) · [官网隐私说明](https://agigalaxy.org/privacy/)

本页说明当前产品和源码中的主要数据边界。部署者仍需核对自己的采集、服务配置与用户告知，不能把设计方向当作所有环境均已执行的保证。

## 本机与在线账户

本地银河 ID 和履历由客户端管理。普通网页登录使用在线账户，网页登录本身不会读取本机履历或创建本地 ID。关联关系保留各自控制和来源，账户登录不自动取得 ID 私聊、工作、密钥或全部设备权限。

本人资料、公开查询选择和上传档位分开保存。停止公开不等于删除本地资料；移除客户端不等于删除云端副本或撤销设备。

## 四档上传范围

| 档位 | 范围 |
|---|---|
| 1 · 仅本机 | 不上传本地工作材料 |
| 2 · 履历概况 | 允许结构化工作类型、角色、时间、结果状态、来源标识及主要模型工具版本；不包含标题、自由摘要、私人项目名、路径或原文 |
| 3 · 工作内容 | 在概况之外，允许所选工作说明、过程摘要及实际保留材料 |
| 4 · 会话归档 | 另行启用并选择准确原会话范围后，才允许相应会话上传；只选最高档不代表包含全部会话 |

初始化默认第 2 档。没有接入或未选择同步目标时，默认档位不会主动上传。完整会话的本地归档也需准确选择，不由普通工作履历自动推定。

密码、令牌、API Key 和私钥不因较高档位纳入允许材料；资料处理仍依赖实际采集与过滤范围。详见[Native 说明](native-client-v2.md)、[上传范围源码](../packages/galaxy-core/src/upload-privacy.mjs)和[归档源码](../packages/galaxy-core/src/conversation-archive)。

## 共享与来源

公开展示、私有同步、对特定接收者的许可和完整文件导出分别判断。源内容每次按当前对象、版本、受众和期限检查；账户关联、收藏、旧成功回执或已经看过某段内容不授予新的读取权。

资料包的文件签名与来源的当前许可分别说明。已保存到接收者本机的文件不能靠服务撤销远程抹除；服务应准确停止其可控制的后续读取。

## 事实、摘要与判断

实际宿主观察、用户自述、自己的 AI 整理、外部对端报告、技术检查与独立验证保留各自来源。工具完成不自动构成目标解决，外部凭据不变成银河官方出证，平台不据此给人生成通用可信度评分。

官网中的预设回答和隔离检查的合成资料应就地标识，不作为实际用户画像、增长或成效。完整运营分析和 AI 治理能力仍按[项目状态](project-status.md)建设，不从规划推定已经在生产采集。

## 读取、导出与删除

本人本地记录、私有原会话、云端工作副本与在线账户资料有各自管理入口。删除本机原件、删除工作事实、停止同步与删除云端副本是不同动作；未知结果按原操作核查，不重新制造副本。

读取失败或当前权限无法核实时，受控正文按适用规则收起，独立草稿和必要定位可保留。具体账户公开范围见[公开查询合同](account-public-query-v1.md)，内容和附件见[账户参与合同](account-participation-v3.md)。

云端完整会话可能涉及额外资源与服务条件，但具体付费范围、价格、免费额度和停止服务后的保管条款不能从源码推定。本说明不承诺无限存储或未经验证的永久保管。
