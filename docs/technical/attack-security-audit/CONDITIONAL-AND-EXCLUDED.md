# 条件性线索与排除项

这些项目不计入三项静态支持的可用性发现。此页只归纳中止前或其他已完成审阅留下的判断，没有继续 runtime 技术分析。

## C01 身份关联授权 URL 可转交

已有静态链表明：持有自己有效设备绑定的发起者可创建关联事务；他人接受该授权 URL 并在配置的 IdP 完成认证后，事务仍由原发起设备查询与签名确认。后续 account-owned 社区对象权限可能依赖关联账户。潜在安全边界是“浏览器身份持有人是否明确同意关联到所示设备”，不是 OAuth state、PKCE 或设备签名失效。

必要条件包括允许的身份提供方、有效设备绑定、受害者点击并完成认证、关联约束允许、具体后续操作所需范围及签名；社区影响还要求相关账户对象与有效当前版本。模板有通用关联提示，但没有证明实际部署是否展示清晰的设备/主体和范围同意。产品允许合法跨设备关联，不能简单把跨浏览器行为本身定为漏洞。

**处置：条件性身份同意风险，暂不评级；不是静默、零点击、匿名账户接管。** 不声称可读取旧归档、继承聊天成员资格或取得管理员权限。验收应确认显式浏览器侧设备/主体/范围批准与事务绑定，保留合法跨设备交接。

来源：此次 `auth/attack-notes.md`。核心 blob：`accountlinks/links.go` 为 `2de0c98d55eed90969695af3033c274729a8212b`；`accountlinks/service.go` 为 `3d65c40100c74d7421ba74db36d314f35dcc02ab`。后续效果证据：`community/identity.go:46–59,109–155`，blob `5166ece1a197b2389a280e2bc55afe5e76e1e097`；`community/write.go:388–440`，blob `8cda2b4788ba1c8e432a34672d8da5d26c20fb7b`。独立检查结论在该 auth 笔记中已归并；本次没有另行验证部署。

## C02 SQL 函数权限边界

已保存 runtime 笔记认为部分 SECURITY DEFINER 函数存在临时 schema 名称解析风险。需攻击者先获得适用受限角色的任意 SQL 能力、数据库 TEMP 权限及相应对象创建条件，函数所有者也必须具有更高权限。未建立匿名 HTTP 初始入口，未验证线上 ACL 或 owner。

**处置：仅部署条件性权限提升线索，不是已验证提权或 OS 执行。** 原有位置 `go/internal/databaseschema/sql/106.sql:25–38,44–61`，blob `f474629c180d3dccb3322588bcee1d18772c5e2f`。仅保留此次 runtime/findings.md 的结论，不补充触发步骤或继续验证。其引用的官方说明为 [PostgreSQL 函数安全说明](https://www.postgresql.org/docs/current/sql-createfunction.html)。本整理未重新联网核查。

## C03 Redis 部署适用性

已保存 STATUS 记录默认 discovery op-kv 选择 Redis 7.2.5，提示 CVE-2025-49844 版本适用性风险，并明确需要私有桥接网络可达和 Lua 执行能力。没有发布 Redis 主机端口、互联网初始入口、实际镜像/ACL、容器逃逸或主机权限的证据。

**处置：条件项，不能写成互联网 RCE。** 版本号与条件来自中止前记录，不是当前部署观测或本次新漏洞验证。后续处理受平台中止边界约束。

## E01 Outcome export 策略保留项

独立 copy grant 撤销后、清理前，先前合法获准的接收方是否还能获得一次新的 Page 文本响应，涉及复制授权撤销政策与实际清理时机。**保留为策略限定项，排除在确认攻击发现之外。** 不是任意用户第一次跨用户读取，不是原消息 TTL，也不是召回此前已合法下载的副本。未确认清理窗口，不升级严重度。

## 其他不升级项目

- discovery 上游无显式响应字节上限：需恶意/被入侵的已配置上游或可证明普通输入放大链，尚未建立。
- Profile/discovery 留存观察：没有完成攻击边界证据，不作为漏洞。
- OpenPanel、tar、portable 原作者标签：原记录缺少适用攻击者输入或权限消费链，保留条件/加固或排除标签。
- 依赖版本命中、危险 API 名称、测试断言、UI 权限选项变化本身，不足以证明漏洞。
- Web 所审路径未发现已确认可利用漏洞，不意味着全仓库、依赖内部或部署无漏洞。
