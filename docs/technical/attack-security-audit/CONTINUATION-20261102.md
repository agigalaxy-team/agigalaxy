## 一、结论未升级

原三项保持“静态支持、暂定中等”的可用性风险，详见 [FINDINGS](FINDINGS.md)：

- **A03 搜索引用**：内部翻页重复重建当前可见语料。直达入口仍扣一次默认 25/60 秒/IP 搜索分页额度，另受提交额度约束；information 包装器有独立 60/60 秒/IP 与 1–8 项顺序选择限制。不是无限请求、私有数据泄露或已验证停服。

- **A01 官方账户归档**：nil-origin 路径缺少账户累计预算的证据，不代表所有权、CSRF、单归档大小或请求频率限制不存在。没有实际容量耗尽验证。

## 三、已补充的普通静态边界

以下是具体阅读所得，不是模块全量安全认证。

### 1. 同意签名、当前身份与本人回执

1722107 中，`deviceauth/envelope.go` 的指定验证函数，以及 `consent.go:68–189`、`service.go:171–244`、`current-control.go:1–28`、`control.go:31–95`、`http.go:27–100,145–171,217–223`：

- 类型化 Ed25519 签名针对原始 header.payload，使用当前认证控制公钥，不接受封装中自选密钥替代。
- 同意绑定主体、设备绑定、endpoint、范围、时间和精确内容；事务中重新检查凭据、绑定与当前控制状态。
- 请求体和签名意图均有大小限制。exactJSON 的键集合校验不等于拒绝 JSON 重复键；尚未建立由此导致的解析差异绕过。
- 本人同意回执按当前主体读取；保留操作回执查询要求新鲜签名绑定精确挑战，只返回本人元数据，不返回新凭据或快照正文。

公共控制历史中的公开密钥、签名不作为认证秘密泄露结论；未对所有创建、撤销实现及数据库并发效果作运行验证。

### 2. 身份组合、个人声明和联系请求

- 身份组合用当前查看者读取来源，成员关系不自动赋予其他成员身份。配置来源检查当前可读原版本、撤销状态、内容摘要与作者。
- 提议及批准绑定 endpoint、组合、操作、原始 payload 摘要、主体和控制代际；创建要求新成员批准，修订检查新旧成员集合，提交前再查当前状态。
- 单个当前成员撤销整个组合属于明确产品规则，未据此列漏洞。
- 个人声明有独立签署的分享期限，不能把其长于短期准入凭据直接当作绕过；显式撤销、当前控制、摘要和删除边界仍需满足。
- 联系请求的 HTTP 读取者来自当前认证身份；旧同意、原发送者和接收者检查与正文授权分开核对，没有执行实际房间创建或消息发送。

### 3. 附件、本人导出、目录与社交来源

- 社区及聊天附件补查当前身份、来源可读性和返回正文条件；存储、扫描、擦除真实效果仍未验证。
- 反馈本人导出绑定账户、endpoint 和操作；分页与截止点有界，之后删除的记录不还原正文。
- 本人附件读取前后检查真实会话与同一账户，要求附件归属、可用状态、大小和摘要；后台读取权限另行检查。
- 注册目录要求 registered.read；邮箱、发行者等身份信息另受 identity.read 控制，拒绝无权限的邮箱筛选。查询参数化和输出收缩不替代所有原生身份提供者验证。
- 收藏、关注及旧回执不授予源内容权限；当前来源关闭或失效时不因关系存在而恢复正文。旧操作同摘要重放只读回执，不自动恢复随后删除的关系。
- 事务快照内二次检查不证明所有在途撤销都瞬时生效。

### 4. 前端卡片、模型表单与消息队列

补读客户端、会话回合、滚动、通信视图、模型编辑/删除/设置/视图模型及队列辅助文件的明确范围：

- 回执与原操作/运行绑定；有限重试要求错误状态、已知业务尚未启动、原输入及当前发送权限。
- 队列按操作者和业务上下文隔离，先记录尝试；结果不明时通过原操作读取恢复，不能据此声称后端没有重复执行风险。
- 模型原始密钥与配置快照分开；失去会话或权限、恢复、删除等路径清理相关临时状态。新的回退/场景选择重置数据政策批准状态。
- 草稿按操作者保存在会话存储中；未声称退出会清除所有历史草稿键。
- 前端渲染与按钮门禁均不是服务端授权或真实执行效果的证明。
