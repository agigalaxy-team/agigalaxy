# 逐文件覆盖台账

[进度快照](progress.md) · [字段和分片清单](manifest.md)

coverage-*.md 保存全部基线文件路径、blob SHA、大小、审阅状态和证据定位，包括所有未审文件。每份文档的 JSON 代码块可直接提取解析；它们是审计报告数据，不是应用配置。清单同时给出完整 Markdown 文件及原 JSON 数据的哈希，便于无损核验。

**当前证据发布限制：**详细逐文件检查说明及原始记录已保存为不可变快照，尚未全部公开。ledger 文件/行号是后续详细证据发布的稳定标识，不表示现在已可访问。仅凭台账不能认定安全验证通过。

full（完整阅读）只表示同一基线blob的完整静态阅读记录；hybrid（语义与结构混合检查）、structural-only（仅结构检查）、partial（部分阅读）分别统计。本快照不证明已执行测试、安装依赖或探测生产。main增量另账，不混基线。
