# 逐文件覆盖台账

coverage-*.json 为可读分片，保留全部基线文件路径、blob SHA、大小、审阅状态和证据定位，包含所有未审文件。manifest.json 定义字段、状态与方法含义、来源记录映射及固定 GitHub 链接模板；progress.json 是明确时间点的统计。

**当前证据发布限制：**详细逐文件检查说明及原始记录已保存为不可变快照，尚未全部公开。本目录的 ledger 文件/行号是后续详细证据发布的稳定标识，不表示这些文件现在已可访问。仅凭台账不能认定安全验证通过。

full（完整阅读）只表示审阅者记录了对同一基线 blob 的完整静态阅读；hybrid（语义与结构混合检查）、structural-only（仅结构检查）、partial（部分阅读）分开统计。本快照不证明已执行测试、安装依赖或探测生产。main 的 6ab0e40 增量另行记录，不混入基线覆盖。
