# 银河数据保留策略 v0.1（用户已确认）

确认日期：2026-09-11（Asia/Shanghai）。用户在完整推荐策略表后确认：“你说得对，就按这些来。记录一下”。

状态：**产品策略已确认，尚未作为新运行配置实施。** 用户此前要求暂停开发，本次仅记录决定；不启动清理任务、不修改备份周期、不部署聊天功能。当前实现以[数据生命周期](data-lifecycle-v0.1.md)及实际运行证据为准。

原则：成果履历长期保留，普通交流限期保存，原始工作资料以本地保存为主，用户可以导出和删除。保留期限与授权有效期分别管理。

|数据类别|已确认的默认保留期限|用户控制与到期处理|
|---|---|---|
|本地身份私钥、未选定的代码和原始上下文|本地由用户管理；官方云端不保存|用户明确选择提交的部分才进入对应云端类别；本地身份私钥不随材料上传|
|个人资料、公开身份信息、服务绑定关系|服务关系存续期间|可修改、解除绑定或申请删除；退出Official不等于销毁本地Galaxy ID|
|已确认的Case、成果摘要、Proof、能力履历|长期保留，不因普通不活跃自动清空|支持撤销展示、纠正、导出和删除申请|
|支撑成果的必要Evidence、验证记录|随对应成果保留|只保存必要且已获授权的材料；证据删除或失效时同步更新成果的可验证状态|
|云端未发布草稿|最后编辑后30天|到期前提示；继续编辑可续期，本地副本不受影响|
|普通聊天、临时协作交流（未来功能）|每条消息发送后90天|可选7天、30天、90天；经相关作者授权整理成Case的内容另行保存|
|普通附件、临时上传文件|上传后30天|到期显示“附件已过期”；纳入正式证据的文件改按Evidence规则处理|
|普通通知、提醒|产生后90天|到期清理通知，不删除关联Case或成果|
|登录挑战、临时会话、下载凭证|按各自有效期；失效后24小时内清理临时记录|失效立即禁止继续使用；必要审计另存|
|普通运行与错误日志|产生后30天|自动滚动清理，避免记录业务正文与凭据|
|授权、撤销、安全事件和删除审计|授权失效或事件结案后180天|保留必要操作信息；这是产品默认期限，并非统一法定期限|
|数据备份|30天滚动窗口|已删除数据随旧备份淘汰；恢复备份时重新应用删除记录|
|长期不活跃用户|12个月后标记不活跃|暂停活跃推荐，保留成果履历；不默认采用账户自动销毁机制|

## 三种操作

1. **撤销公开**：立即停止后续授权展示，内容仍可由本人管理。
2. **删除数据**：立即隐藏，普通删除目标为主库7天内清理；备份在主库清理后最多30天淘汰。必要审计单列，已被他人下载的副本无法直接追回。按这两个目标相加，普通主库及备份流程最长37天；不将此数字套用于另列审计或第三方副本。
3. **整理为长期成果**：用户主动选择材料，并具备相应授权后保存；收藏或聊天置顶本身不扩大使用权限。

长期保留指服务关系存续期间为持续积累成果而保存，仍受用户删除、服务退出及对象授权边界约束；不构成永久不可删除承诺。原始文件、证据记录、派生履历、搜索候选各按实际类别处理，不能因为保留Proof就自动保留未经选择的全部上下文。

## 参考依据与银河选择

以下为2026-09-11查询核对的官方说明，作为产品设计参考；上表期限是银河已确认的选择，并非上述应用的统一配置。

- [Telegram隐私政策](https://telegram.org/privacy)：普通聊天支持云端保存和多设备访问；秘密聊天采用不同机制；默认连续18个月不活跃会触发账户及云端数据删除，用户可调整。银河借鉴内容分层与用户控制，对成果履历采用长期保留和不活跃标记。
- [微信隐私保护指引](https://weixin.qq.com/cgi-bin/readtemplate?lang=zh_CN&t=weixin_agreement&s=privacy)，2026-08-17版：聊天历史保存在终端，可备份、删除和迁移；朋友圈等内容按功能存储。银河将普通交流与长期成果分开。
- [WeChat国际版隐私政策](https://www.wechat.com/en/privacy_policy.html)，2026-08-06版：普通消息送达后不久从服务器删除，最迟发送后72小时；媒体通常120小时，收藏和群公告等有不同规则。这些期限不等同于国内微信规则；银河借鉴临时传输与主动保留分别处理。
