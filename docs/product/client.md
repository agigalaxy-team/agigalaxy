# 客户端、宿主与本地工作积累

客户端按[用户侧模型职责](overview.md#人模型与系统)进入已有 AI 工作环境。宿主插件可承载客户端；银河通用插件提供通用连接能力，两者不能混称。Skill＋MCP、命令行及嵌入面板按实际宿主支持交付，不要求无 UI 环境先有插件商店或 GUI。

## 初始化与连接

初始化先发现适用的[本机身份](identity.md#身份连续性与关联)，没有时再创建，可跳过官方账户注册和关联，以本地身份和履历开始使用。需要线上服务时再接官方或第三方 Hub，上传范围沿[数据规则](data-and-files.md#本地工作资料上传)办理。

客户端走银河 HTTPS 接口；Keycloak、Prosody/XMPP、数据库、存储及扫描器由 Hub 或官方运营者维护，不是普通客户端前置。具体运行时和宿主支持以发行说明为准，不能把单一宿主覆盖推成全宿主支持或完整离线安装。

## 普通真实工作的默认本地积累

初始化协议说明默认记录内容、用途和本地保存方式。客户端取得的普通真实经历默认积累到本地 ID，即使未查询银河、未向外求助、没有工具调用也可记录；不要求先开菜单、建 Task 或逐项确认。写作、研究、学习和讨论保留工作价值。该记录不等于持续模型关注、默认复制完整会话、上传或网络事实发表。

程序保存实际取得的观察、来源、处理位置及环境版本；自己的 AI 按新增材料整理工作目标、尝试、修订和可读摘要。用户消息、AI 可见回复、工具实际结果与产物引用分别归属，多轮可归并同一工作，但不改写原行为者与历史；结果含义统一按[工作事实](collaboration.md#事实结果与经历)解释。

| 时机 | 程序职责 | 模型边界 |
|---|---|---|
| 激活或重连 | 接续身份、上下文与处理位置 | 不为初始化单独调用模型 |
| 新消息、回合或工具完成 | 保存关联、真实状态和新增范围 | 自然阶段整理，不逐流式片段调用 |
| 空闲或阶段收束 | 合并新增、标记未覆盖部分 | 有新增且宿主可执行才运行，空闲不等于已执行 |
| 主要环境变化 | 读取、比较并形成版本 | 不猜安装状态、不预估能力变化 |
| 停用或中断恢复 | 保存位置、补取、去重 | 不强行关机总结、不补造遗漏经历 |

有事件接口优先接事件，有正式查询接口则补取获准材料，仅 Skill＋MCP 可由宿主模型提交结构化记录；无读取或执行能力时说明具体限制，不扫描无关历史。房间 Watch 不等于观察宿主前台会话。模型暂不可用仍保存可观察事实，以后只整理未覆盖部分，不由官方模型补做；网页返回宿主的输入行为见[AI 接续](experience.md#网页与自己的-ai-接续)。

结构化观察、工作摘要和原件引用或获准副本分开管理。摘要保留来源、覆盖及修订，不伪造房间 ID；宿主原件消失且无副本时说明不能回查，不因来源链接存在承诺永久恢复。具体保存范围、期限、批次和存储组织由实现合同定义，不堆成无限增长状态。

## 环境版本、摘要与关注

客户端读取主要环境事实并比较变化，工作引用当时观察到的版本，ID 保持稳定。下一次选择的模型与回合实际用的模型分别记录，未知保持未知，晚发现只记观察时间，不倒填精确切换时刻。版本归因不解释能力增强或减弱。

个人摘要默认本地，可手工整理或用自己的模型，可选同步本人私有空间；生成不自动发房间，同步不等于分享。完整会话归档是另一项范围，见[数据规则](data-and-files.md)。持续关注需实际选择范围、期限及停止方式，事件优先、回退轮询由程序处理；没变化不调用模型、不发空报告。普通打开网页和聊天不默认启动监控，关闭后不周期催开，宿主不可运行时说明实际状态。

本人选择与推荐引用可保存在用户端以继续工作，无需手工维护“快照”；若另选云同步，不随个人摘要开关自动开启。获准历史分页连续读取全部允许范围，不逐页重新确认；AI 可参与普通主聊天，不强制设 AI 子区或主响应者，程序继续去重和防循环。

AI 参与设置在同一表单说明当前对话、自己的客户端、允许行为与期限，调整默认保留原到期时间，已停止范围留历史。授权只说明允许行为，不证明宿主仍在运行；个人摘要、重点与备注留原对话，不能因简化账户中心另造一份重复管理目录。

## 建设者、Worker 与专业流程

工具页先说明用途、条件及在自己环境的使用方式，再关联真实尝试和结果。配置突出已知环境与限制，缺项保持未知。专业操作可登记 Agent、外部来源适配、社区、Worker Pack、范围报告和维护公告；分组表单复用已有资料，JSON 导入可选，不要求手填内部关系。

Worker 节点身份由节点运营者提供，无目录时不冒用项目作者。Pack 只在 Worker 项目编辑和读取，保留来源、版本、许可、依赖与权限；安装不自动接单或持续监控。仅实际配置的非作者评估者可提交独立范围报告，作者登记与独立验证分开。未测试明确显示未测试，日期保留原精度，哈希和版本不得生成替代值；节点声明、本人报告、CI 来源与原工作结果分别表达。

支持范围在草稿期间变化时，除[通用草稿规则](experience.md#草稿返回与提交)外，还保留不再匹配的旧检查说明，供作者判断如何修订报告。
