# 身份、账户、设备与授权

Galaxy ID 承载稳定主体及其履历，银河在线账户承载线上登录、参与和获准数据。两者均可对应个人、组织或 Agent，分别保留主体类型；Agent ID 关联个人账户仍是 Agent。正常客户端默认个人，组织为额外选择，Agent 使用 Worker 特殊客户端；人在 AI 宿主中用普通客户端不会变成 Agent 主体。

## 身份连续性与关联

本地 ID 类型不可修改，初始误选须重新创建。长期独立工作环境保持稳定 ID，主要环境变化用版本归因；安装另一兼容客户端、切换宿主或客户端名称不自动创建新 ID。默认发现并接续适用本机身份，多个候选确有歧义时再选择，不合并独立主体、履历或旧权限。

一个账户可关联多个 ID，同一 ID 也可在同一服务关联多个账户。各关联保留实际发起 ID、目标账户、数据及授权来源，不跨账户继承权限或改写历史。在允许范围内可双向查 ID、账户及外部认证。在线账户主体类型可依相应条件更正或变更，保留前后信息、时间和依据；具体办理条件与路径仍须细化，不提供任意切换，不改本地 ID 类型、旧行为、签名或认证含义。

解除一条关联后停止经该关系续传与代操作，其他有效关联独立处理；既有资料按自己的许可、期限和账户展示设置处理，依赖关联有效的许可随条件失效，不从解绑推定全部资料仍公开、一律撤权或副本已删除。账户在关联 ID 之前的帖子、回复和贡献仍保留原账户及当时来源；后建 ID 可获准读取或引用，但不变成过去作者，不反向迁移成多份独立贡献。这是既有归属与许可分离规则的组合解释，不是新增全局保留政策。

ID 只在本机银河客户端创建，网页可与本机配合，不能独立生成并缓存另一套身份。废弃的浏览器建 ID 不保留兼容恢复或日常入口，不从旧 active 状态自动接续或转属账户。列表、网页连接和登录邮箱都不证明本机控制；真正接续核查签名、设备与当前授权。

## 注册、登录与普通参与

访客直接阅读实际公开内容。官网注册、发帖、回复与私聊等普通参与使用在线账户，不要求本地安装、Galaxy ID、模型或外部认证。发布或参与具体任务才接续本机 ID 及获准资料，不将该要求扩大到全部社区操作。账户中心按真实登录状态显示概览、本人内容、收藏、设置和本机接入；设备、身份、关联在同一接入过程中就近说明，不重复造栏目。第三方 Hub 的实际接入属于本地及开源模块，官网仅提供必要关系图解。

注册只填邮箱，核验后设置密码，不要求姓名或自选用户名。未完成设密的记录可在新事务重新核验后接续，保留原资料；一个事务完成后旧页面不能重设正式密码。正常登录用密码，注册和找回采用邮件验证码，支持完整粘贴及可用一次性码填入。登录保留非敏感输入，不保存密码或验证码；其余接续按[草稿、返回与提交](experience.md#草稿返回与提交)，未接通的认证提供方不能显示可用。

账户公开 UID 固定唯一、不可编辑，要求 6–16 位大写字母数字混合编码；准确发行长度由实现定义。初始展示用户名沿用 UID，可编辑且不改变 UID，已有自选名称保留。UID、内部 UUID、本地 Galaxy ID 各自独立，UID 不是秘密或权限证明。

## 设备与恢复

旧设备可用时由旧设备确认新设备；旧设备均不可用时用恢复码。首次设置可跳过，之后补做；设置后复制或下载并声明已保存，不增加回填考试或周期催换。“我已保存”不是备份完成证据。恢复码默认隐藏、主动显示，秘密不进入日志、报告或公开页。

启用前先保存，恢复时先保存替换码再连接原任务；刷新继续待保存的同一新码。成功使用后更新恢复码，旧设备失去控制，旧提交不得重新激活。刷新或短期会话到期可沿有效原连接核查接续，不另建绑定绕过断开、撤销或期限。

恢复身份不等于恢复所有资料权限。完整原工作暂不可读时可一次选择当前允许的本人记录，刷新沿同一范围和期限；新增范围需明确选择，不授予他人资料。取消请求或结束征集另作明确动作，已发生工作保留。恢复诊断可复制但不含秘密。

## 授权与代表关系

新增受众、代表动作或持续读取只补所需最小选择。用户看“谁可看、允许做什么、多久”，协议字段不成为日常表单。可选同步、模型或关注被拒绝不影响无关阅读和交流。

共同展示多个身份不合并身份、作者、额度或私有许可；各身份控制者分别确认分组，当前成员可明确撤销整份关系，原签署历史保留。共同管理只约束确实采用的对象和房型，同一人的设备不产生多票，IP 不能推定同一主体。原回执不构成永久阅读许可，当前展示与派生停读统一见[保存与失效](data-and-files.md#保存与失效)。

后台人员、稳定 AI 工作账户及其委派见[后台规则](admin.md)和[自动运行](admin-automation.md)，普通在线账户不提供提权入口。
