# 请求、协作、事实与方法

Project 表达持续目标，Opportunity 表达长期参与需要，Task 表达具体请求，Room 承载交流。需要持续目标才建项目，确有独立范围才拆任务，普通讨论不自动转成工作项。

## 从当前工作获得帮助

自己的模型从获准原目标、已有尝试、观察和局限准备可编辑摘要，用户也可直接请求主动评审或诊断，无需先证明失败。已经决定向外求助时，采用准备公开请求并提供适合联系的候选清单的默认方向；定向发送仍可选，私人材料与人选不随公开请求外发。发布、找人分别处理，空候选不阻止明确发布，发布不自动邀请。

从原工作继续时选择是否保留关联、引用哪些准确版本，计划与已执行尝试分开。接手者在正文旁读作者实际选择的观察与限制，不附带整份私有背景。需要联系时才写具体帮助和联系依据，按已有明确发送指令办理；分别沟通或多人讨论由当次情境决定，名单不自动形成群聊。

交付围绕文件、链接或说明，接收者直接打开、使用和反馈，系统关联原工作及作者。合作反馈说明目标是否清楚、实际范围是否相符及具体情况，只对本人和请求者开放；修订追加原因与更正，保留原记录，不抹去历史。

共同维护项目时按姓名选择联系人或成员，角色旁解释实际能力。管理转交须对方阅读原项目并接受，角色不扩大其他资料权限。项目管理状态不冒充完成度，机会按真实需要更新、暂停或结束，不强迫定期复核维持可见性。

## 消息、邀请与房间

对话以当前消息、阅读位置和输入框为主，旧历史与个人摘要按需检索。联系邀请说明发起者、目的、背景与正文，接收者可补充回应，一次接受进入该邀请形成的对话。已在房间或待回应者不重复列入邀请名单，准确身份引用保留专门入口。加入、退出、静音、屏蔽各有独立含义，不扩大资料或设备许可。发送、草稿结清和返回沿[通用操作规则](experience.md#草稿返回与提交)。

通知按姓名选联系人和对话成员，只合并本次修改，保留其他设备无关设置。屏蔽说明对后续联系的实际影响。成员调整显示谁提出、改什么及当前能作的回应，只有原发起者能撤回；期限过后或成员关系改变进入历史，执行仍验当前条件，不要求重复同意。

无房主临时聊天室中，其他成员明确退出而只剩一人时，可关闭地提示解散或成为房主，由用户选择，不自动改型；初建等待邀请与断网不算退出。特殊房型的共同管理、接任和解散规则不默认套到普通聊天。

## 事实、结果与经历

Task、Case、Attempt、Configuration、Intervention、Result、Evidence、Verification、Resolution 分别表达请求、背景、尝试、环境、介入、输出、依据、具体检查与解决情况。内部关系不等于逐项填写要求。可可靠取得的作者、时间与关联自动记录；用户陈述、模型整理、宿主事件、工具报告和独立检查保留不同来源性质，无法确定的贡献与结论保持未知。

收到输出、采用结果、认可贡献、通过某项检查和解决目标分别记录；工具成功、模型自称完成或会话空闲不自动证明总目标成功，缺少回应仍为未确认，不倒逼参与者完成证明流程。多人贡献按实际来源保留，转载和模型总结不增加独立证据。自动本地积累及环境归因统一见[客户端合同](client.md)。

有分歧或材料不足时保留部分、未知及冲突，不从一次检查或反馈推定恶意；有限建议不要求独立重跑才能成立，也不产生持续劳动义务。跨 Hub 携带验证声明保留原机构、签署者与实际验证范围，不表示接收方已经独立复核，判断职责仍按[平台边界](overview.md#人模型与系统)。本人也能补充非软件经历，修改保留声明性质，不包装成原始观察或他人认证。

完整经历按过程、结果、来源及时间或主题定位；常用概览与深入资料沿[信息层级](experience.md#信息组织与视觉)组织。认可说明发行者、规则、计入和未计入依据及期限。本人展示声明可持续或到日停止，保存动作的许可期限不自动等于展示期限；更正、撤回或控制变化重新核查，删除数据不因编辑入口恢复。

## 方法与应用

正式 Capsule 从真实成功工作结果提炼，保留来源、版本、步骤、核验方法、适用条件、限制和许可。经验帖可包含未完成尝试、反思或未验证想法，不因此升级为正式 Capsule。填写核验方法不证明已执行，报告成功不冒充独立验证。

整理时先阅读准确来源，再编写正文，来源许可明确原作者、准确版本、使用者、用途、受众、期限和署名；能读不等于能发表。消息引用选择原对话和原消息，读者只取得自己可读的所选原工作及准确结果，不借发布者权限读取整份案例或后来私有更正。预览提交沿[通用操作规则](experience.md#草稿返回与提交)，来源变化沿[失效规则](data-and-files.md#保存与失效)。

阅读、收藏、实际应用和再次验证分别成立。记录应用时选择另一项实际工作及所用准确方法版本，带入已有结果和环境，补充采用部分，保留部分完成、差异与未知限制。阅读后可以直接借鉴并结束，不要求回报全部后续。

## 分享与资料包

把消息或附件留作工作材料时，选择准确内容、目标工作、用途和受众后向原作者申请；作者读清原文和范围，一次批准或拒绝。原对话读取与独立副本许可分开：原消息变化不自动撤销有效副本，副本撤销或到期停止其正文读取。

资料包准备、打开、材料携带许可与工具格式各按用途进入。准备时选择介绍、已有工作、获准材料及接收者；携带许可明确作者、准确记录、持包人、受众与期限。更换本人原材料时保留已选持包人、受众与期限，签署后的原文件可再次保存。导入文件完整性与签名、来源当前许可分别检查，不能用字节校验代替当前访问许可。失效、副本和导出的共同规则见[数据范围](data-and-files.md)。
