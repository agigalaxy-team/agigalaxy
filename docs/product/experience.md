# 跨入口体验与连续操作

页面从用户当前目的组织：先呈现相关内容，动作就近发生，结果回到原处。原型、生图和既有路由用于说明意图或定位实现，不能把其中导航数量、示例字段、假数据、图标或按钮直接当成业务决定。

## 信息组织与视觉

常用页面展示概览、真实内容和可用动作；完整背景、历史、来源和专业参数在主动深入时按用途组织，Agent 按问题读取获准资料。完整数据可取得，不等于首屏铺满记录、证据、状态标签或工具响应。人物用形象、短介绍和代表内容帮助识别，荣誉用含义清楚的徽章，深入资料另有阅读结构。

官网首页简述用途，同时提供真实内容及发现、发布、参与入口；没有内容时显示相关空态，不虚构活跃人群、热度或效果。技术介绍、安装和协议说明放在对应深度，不成为阅读前置。私人开发进度、执行汇报、验收步骤和架构教学不进入产品日常页面。

导航围绕稳定目的而非后台对象组织；旧 history、privacy、identity、summaries 等兼容路由不要求恢复成独立栏目。网页、宿主面板、终端和无 UI 工具共享主体、权限及成功含义，呈现按实际环境适配。共用外壳、字体、间距、色彩、控件和稳定页签保持一致；状态不只靠颜色，键盘、焦点、对比与阅读均可用。加载和动效帮助理解，不打断输入或思考。

## 已选页面结构与品牌

官网及用户页面使用可用视口全宽、一致外边距和对齐关系，取消窄居中外框；长正文只在页内约束合理行长，不靠新增虚构内容填空，也不调用浏览器全屏 API。发现、社区、消息和账户共用固定窄侧栏，首页入口在发现上方；切换只更换右侧内容，内容滚动不带动侧栏，账户二层目录不扩成全站导航。

首页是无全局或局部侧栏、轻量顶栏的完整连续长页，采用已选长页 C 的设计方向。少字、少框、二维表达及原位弱交互保留，不改成人物照片信息流；图形支持悬停、键盘聚焦和触摸，不引入视频控件或自动跳到下方。白色为主、粉色局部点缀，直接沿用已选原始轨道 Logo，不生成近似替代图标；轨道式加载在减少动态时保持静态可用状态。旧粉白固定模块和密集框线不因曾采用而恢复。

账户沿已选 B 的内容组织，消息采用已选 A 的会话、正文及共享资料区；社区沿已选侧栏和内容组合，左侧功能／频道、中央左图右文内容列表、右侧关注频道与精选，窄屏收进频道导航。图片只承载真实封面或缩略图，无图保留文字行；外部精选标出处和图像署名，不能当作银河帖子、真实热度或独立子版块。

产品页面不使用入口箭头／chevron 或折叠式内容组织，以直接排布、文字页签和有组织详情替代。后台 AI 等辅助工作区未聚焦时可紧凑收起是后续明确例外，不能扩大为全产品多层折叠；后台具体结构见[工作区域](admin.md#工作区域与设计)。这些设计选择不等于对应页面已完成验收，图稿示例不成为正式条款或业务参数。依据：[直接要求及后续纠正](../../originals/conversations/CURRENT_USER_REQUIREMENTS_2026-10-09.md)。

## 草稿、返回与提交

复用已有身份、上下文、输入和有效选择，只补影响当前动作的缺项。合法草稿按当前身份和服务隔离，保留文字、选人、准确来源、筛选、页签、阅读位置和焦点；登录、刷新、关闭、返回与短暂离线可继续。切换入口不得覆盖已有稿；两设备或两身份产生冲突时展示两份实际内容，由本人决定，不静默覆盖。

发布前在同一处看清实际对象、正文、受众及必要期限，一次明确动作提交。编辑直接带回原文，保留作者标点及单条多行内容；技术签名和内部授权不拆成额外确认。服务确认后仅清理该次对应草稿，后来输入仍保留。阅读、预览、生成摘要与准备卡片各按真实含义表达，不自动发送、发表、执行或登记工作；会外预览若实际外发载荷须准确说明。

响应丢失、超时和暂时故障由程序查询并接续同一原操作，先确认是否已经接受，避免重复发送。明确业务拒绝后保留内容并停止自动重发，处理原因后沿原稿和仍有效授权继续。真正改变主体、范围、来源或授权才处理相应差异；不能靠刷新、复制内部编号、查询回执表或新增“继续确认”按钮完成日常恢复。取消、明确拒绝、已完成和可恢复暂停分别处理。

失败在受影响位置说明准确原因和可行下一步，不编造倒计时、进度或永久删除结论。只有需要人工决定的冲突才打断使用；受控正文的离线、撤权与缓存处理统一按[保存与失效](data-and-files.md#保存与失效)。

## 网页与自己的 AI 接续

“用自己的 AI 继续”携带当前目的、所选对象与准确版本引用和返回位置，链接不带原正文、未选材料或私人草稿。客户端沿同一身份重新读取，返回有用正文、有限来源、可继续动作及原页面链接；旧版本不被较新版本悄悄替换。

宿主中放回原工作只追加原未发送输入，不自动启动模型；能否写回由真实宿主能力决定。长正文按实际可读区域分页，阅读不准备签名或触发提交。网页未连接可执行宿主时不能冒充运行按钮，网站链接也不称作远程 MCP 端点。

## 需保持独立的状态

邀请不是回应，推荐不是参与，进房不是接单；消息已发送不是对方已读，模型读过不是人已读。界面可合并相关提醒为一个入口，但每项原通知的已读及当前权限仍独立。工作结果的事实含义见[事实、结果与经历](collaboration.md#事实结果与经历)。实际状态和字段限制以所属服务及源码合同为准，本页不固化卡片数、页容量或重试秒数。
