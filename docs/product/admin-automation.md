# 后台 AI、策略与自动运行

后台以全站共同边界、分领域目标、具体策略三层组织。策略可在“规则自动、AI 自主、AI 推进并引入人工、人工主导并由 AI 辅助”四种当前主导方式间切换，说明谁判断、推进及等待；四种方式共用执行与权限，不是四个风险等级或四套系统。

## 策略生效与执行

程序先处理明确规则、固定计算、定时、到期、受限重试、验权、统计和已有专用能力，复杂语义、上下文与灵活判断才调用模型。重要事件、未覆盖异常及人工接管由人工主导、AI 辅助，优先于普通自动流程。AI 可在已批准业务、对象、动作和参数边界内维护普通日常策略，通过所需检查后生效；改变目标／授权边界、重要变更、校验失败或条件不明交人工，不能自行修改安全边界。

预演按预设变更分类和条件决定，无副作用，不实际发送或处置；基础校验和生效后观察始终保留。新事项用新版，进行中默认绑定原策略／流程、岗位要求及运行参数版本；如需改变在办事项先停后续并单独重评。每次动作仍查最新权限、停用及接管，冻结版本不冻结旧权限。

达到停止条件先阻止问题版本继续执行，可按获准恢复策略采用符合当前目标和边界的版本；无方案或恢复失败保持暂停转人工。已完成动作不因策略更新自动重复或撤销，业务撤销另按所属规则办理。

长期授权独立约束动作、对象、条件及领域。“全部符合条件对象”包括以后出现的合格对象，但每次执行仍冻结本次具体清单并验当前资格；旧空数组不自动表示全部。保存授权与实际处理器接通、模型可用及执行就绪分别表达。

## 工作台与稳定 AI 账户

没有长期自动授权时，即使管理者在聊天中明确下达业务指令，AI 仍先查对象、准备动作及影响的具体操作卡，人工点击后才执行。这是后台业务写入特有的人工步骤，其提交和未知结果恢复沿[通用操作规则](experience.md#草稿返回与提交)，不再叠加确认。任务链接只打开原事项，不自动发送问题，也不借用无人值守权直接写业务。

岗位角色和受托权限交集统一按[后台身份规则](admin.md#用户管理人员与-ai-身份)。运行时用稳定 AI 账户的服务端身份依据，不借管理员 Cookie、密码或会话，模型自报同名字段不能取得权限；自动任务在角色之外另查原计划、策略、长期授权、对象和人工条件。

总控只在人工显式委派的目标 AI、权限上限和动作内维护其他 AI 的专用角色，不能改共享角色或给人员授权。岗位工作要求、日常策略、授权边界与模型配置分开。岗位提示词的读取／修改还需对应业务权限与明确委派，只允许已列目标的工作要求字段，不扩为模型、固定安全边界、值守启停、计划或目标管理。旧委派不自动增加新动作。

每个新工作台轮次从服务端取得自身已保存岗位要求，冻结该轮实际版本；读取其他 AI 的提示词只作为配置数据，不能变成当前 AI 的指令。修改用可审阅完整前后正文的具体卡，回执关联原目标、配置与版本。模型配置及授权边界由人工管理。

## 计划、任务与真实结果

Agno／AgentOS 负责模型与工具运行，现有持久任务和队列负责计划、领取、版本、原操作回执、恢复与业务结果。新增值守默认停用，运维每日时刻必须由人选择；频率、并发、健康间隔及单轮期限等工程默认由实际配置定义，不视为用户固定产品参数。模型完成不等于业务完成。

运行恢复按[通用操作规则](experience.md#草稿返回与提交)，并要求暂停接续绑定同一 Agno 原运行和待决调用，不能悄悄创建替代运行；拒绝或“不办理”不构造批准。离线期间有限合并补查，不用当前日历反推虚构历史巡检。

权限不足时不泄露岗位、计划或任务元数据；系统是否接通、当前权限、委派、处理入口分别表达，未知不能一律说不支持。页面归属统一见[后台工作区域](admin.md#工作区域与设计)。

健康判断需要独立消费者读取心跳和持久任务，不能靠 Worker 自检证明自身正常。岗位均停用与心跳过期分开，采集失败与真零分开，已有告警系统继续承担接收路由，不因出现告警标签声称已经送达。

自动完成量排除普通工作台人工卡，批次区分实际应用、拒绝、跳过及部分失败。调用量取真实模型请求，token 取实际 SDK 元数据；用量未取得显示未知及已观察部分，不按工具数或聊天数估算。按时完成率只覆盖已记账应完成任务及其冻结时限。自动执行的审计来源必须由服务端原任务、工具调用和稳定身份产生，历史缺项保持未知。

## 模型与明确排除项

模型相关设置由人工预设和管理，AI 不参与其配置管理。银河保留完整过程查询回看、基础调用记录、token 和基本用量记账；模型预算、额度、费用预留／封顶和正式账单由上层 API 服务负责。不得恢复被用户撤回的银河模型预算产品，也不增加固定离线 LLM 评测。

设置支持人工选择接口、模型及上下文／输出／思考／超时等实际能力，不增加温度设置。基础费用仅在上层返回或实际价格依据可支持时记录，缺失为未知，不以 token 数冒充金额或供应商账单。过程回看只展示实际保存的获准字段，不宣称揭示模型内部思考，也不因 Trace 结构支持而默认保存全部输入输出；岗位工作要求的受限委派不扩大为模型配置管理。

采用 Agno 原生为主，选择性复用 Langfuse 适合的界面及交互，不由此引入整套 Langfuse 平台。曾研究的 Casbin、预测训练库及其他平台保持各自建议状态，不因页面选择或可复用性变成采用决定。公开内容、私聊、发信、文件、生产恢复的人工边界见[后台规则](admin.md)与[官方消息](messaging.md)。
