# Galaxy 数据与能力授权说明（开发版）

**版本：** 0.1  
**状态：** 产品授权语义和本地实现说明；不是正式隐私政策、服务条款、数据处理协议或法律意见。

## 1. 为什么不是一个总勾选框

Galaxy 的目标不是把“同意隐私政策”变成无限期收集、训练、公开或转交工作内容的许可。每一个跨出本地边界的动作都需要单独、可见、可记录的授权。

> 默认本地；跨边界逐案授权；公开发布逐次确认；训练与商业再利用永不捆绑同意。

## 2. 四类数据边界

| 类别 | 当前本地开发版 | 未来网络版原则 |
|---|---|---|
| Galaxy ID 基础记录 | 本地 Galaxy ID、公开密钥指纹、创建时间。 | 只有用户选择连接/注册时才产生远程关系。 |
| Case 工作摘要 | 本地存储；不自动上传。 | 每 Case 指定接收方、目的、字段与到期时间。 |
| Proof / Evidence | 只能形成 Local Proof Draft。 | Proof-only 公共视图与原始 Context 分开；发布前再次确认。 |
| 研究、训练、商业再利用 | 未实现且默认无。 | 独立选择、可撤回未来使用，并与核心服务拆分。 |

## 3. Consent Grant 的最小字段

```text
grantId
caseId
recipient
purpose
include[]
exclude[]
issuedAt
expiresAt
status: active | revoked | expired
```

它只证明用户在某个范围内作出了授权决定；不证明 Galaxy ID 所有权、能力、结果正确性、独立验证或接收方已经获得数据。

## 4. 永不自动披露的类别

- Secret、API Key、Token、`.env` 和凭据；
- 未被用户选择的源代码；
- 浏览器密码、Cookie、个人通讯内容与设备私密数据；
- 超出当前 Case 目的所需的 Context。

即使将来用户希望分享更高敏感度的内容，系统仍需有单独确认、Secret Scanner、接收方标识、有限期限、可撤销记录和服务端策略控制。协议文本不能替代这些技术边界。

## 5. 撤销的含义

撤销停止未来使用/传递并留下 Audit 记录。它不能诚实地宣称抹去已经发生的、合法留存的或第三方已接收的副本；未来网络版需要把这些保留与删除边界写清楚。

## 6. 需要进一步法务与安全审查的事项

- 正式隐私政策、服务条款、Hub 数据处理附加协议；
- 敏感数据、未成年人、公司/第三方代码、跨境传输和监管义务；
- 账户恢复、密钥托管、审计保存期、投诉与争议流程；
- 任何外部遥测、LLM Provider、模型训练或商业化数据使用。
