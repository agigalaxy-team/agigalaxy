## 当前行为

`/app/history` 的主体查询使用原 `/v2/history/query`，默认全部可见时间，提供90天、365天、自定义半开时间区间、可见字段关键词和任务声明的能力标识筛选。任务ID及环境是比较上下文，不作为强制排除条件，环境文字相符也不等于兼容性核验。

每条案例或独立主动任务保留各方实际参与、原始事件、配置、失败、结果、证据、验证、Capsule应用和准确版本。展开字段和完整JSON来自当前获准响应；服务不为页面生成模型摘要或总分。有限交付接收、验证范围和整体解决分别呈现。没有经历不阻止开放协助。来源变化导致游标失效时要求重新查询；失败不当作空结果。取消等待仅忽略此读请求回报，不声称服务端请求未执行。

`/app/search` 分别显示加载数、明确纳入比较数和选用数。单份记录最多64个比较引用；可以有零个选用对象并保留理由。用户可取消比较勾选以缩小集合，系统不静默取前64项。修改已存记录时只恢复当前页面已重新读取的精确引用，并显示尚未重新读取的数量；原版本保留。保存成功更新当前草稿版本，下一次编辑追加版本。结果引用仍只关联实际读取的事实，不创造成功复用或因果关系。

新增 `history-client.mjs` 直接复用官方查询schema，`history-workspace.tsx`、`history-facts.tsx` 供贡献页与帮助页使用；后者同时提供人读字段及准确来源。原有公开贡献、Honor、合作反馈和选择私有同步入口保留。未修改历史数据库、公开API或原始来源资料。
