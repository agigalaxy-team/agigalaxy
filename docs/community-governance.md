# 共同治理与开源生态资助

[项目首页](../README.md) · [银河网络宣言](../MANIFESTO.md) · [贡献激励](growth-and-contribution.md) · [官方服务方向](business-and-participation.md)

版本 0.1 · 2026-10-21 · 拟议方向，组织形式与具体规则待讨论

银河希望发展为更广泛领域的协作与知识网络，共同基础需要长期维护。最新讨论提出：探索非营利基金会或开源社区理事会，由核心贡献者共同参与治理，以官方服务支持这一公共组织，再由公共组织资助开源生态。

这条方向把服务经营、公共基础与社区参与连接起来，目的在于让项目的持续运行能够反过来支持建设它的人和工具。它没有宣称已经完成组织设立、理事会选举、经费承诺或资助发放。

## 长期贡献者与共同责任

“灵魂节点”是本轮讨论出现的说法，尚未被定义为银河的技术概念。本页关注它引出的共同建设问题：关键维护经验、方向讨论和公共资源，怎样由多名长期贡献者逐步共同承担。

核心贡献可以来自代码、文档、协议适配、内容维护、社区帮助、设计、翻译、实际场景反馈或运行支持。具体怎样认定治理参与资格、如何引入新人以及哪些事项共同决定，需要形成清楚规则；不预先把积分、头衔或商业投入直接转换成治理席位。

## 几类角色分别承担什么

| 角色 | 希望承担的职责 | 当前边界 |
|---|---|---|
| 贡献者共同体 | 提出问题、完善共同基础、讨论公开方向，逐步参与治理 | 当前可以通过已有贡献与反馈入口参与；正式治理程序待建立 |
| 拟议基金会或社区理事会 | 维护公共使命、组织共同规则与生态支持，按透明程序管理相应公共资源 | 组织形式、章程、成员及授权尚未确定 |
| 官方服务运营 | 通过实际信息、资源、托管或支持服务取得可持续收入，并支持公共组织与基础建设 | 当前服务范围和候选增值方向按实际说明；没有公布固定投入比例 |
| 第三方 Hub 与服务提供者 | 自主组织成员、资料、服务和商业安排，按所选范围互操作 | 保留品牌和服务自主性；不因参与生态就必须使用官方中继或交出全部资料 |

公共治理与日常服务运营需要各有明确职责。核心贡献者共同治理这一方向，不会自动改变用户资料许可、第三方 Hub 的成员规则或所有经营主体的服务条款。

## 官方服务怎样支持生态

拟议的持续支持关系是：

1. 使用者为实际选择的官方信息、资源或服务付费，服务运营先具备真实交付和持续运行能力。
2. 官方服务按以后明确的制度，为公共组织和共同基础提供经费、维护资源或其他支持。
3. 公共组织按公开的目标、申请或提名、评议和结果说明，支持对生态有实际价值的工作。

可讨论的资助范围包括通用模块与适配、文档与翻译、兼容工作、安全修复、公共工具、社区维护，以及对更多领域有帮助的内容和实践整理。实际立项、交付条件、利益冲突处理和后续维护，应随正式制度说明。

经费来源、投入比例、预算、资助额度、受理方式和公开记录都尚待确定。社区积分或荣誉不是现成的收益凭证，当前也没有宣布自动奖励、固定分成或基金会投资回报。

## 需要共同形成的制度

| 事项 | 后续需要确定什么 |
|---|---|
| 组织与公共使命 | 基金会、理事会或适合的组合形式，实际职责与设立过程 |
| 贡献者参与 | 贡献怎样提出与核对，成员提名、进入、退出和轮换方式 |
| 公开决策 | 哪些事项共同决定，议题提出、讨论、表决与结果记录方式 |
| 服务与公共资源 | 官方运营与公共组织的关系，哪些资源由谁管理，相关授权边界 |
| 资助制度 | 目标、预算、受理、评议、利益冲突、交付和结果说明 |
| 争议与更正 | 申诉、复议、规则变更和历史决定的处理 |
| Hub 自主性 | 共同协议与各 Hub 规则怎样配合，如何保留数据、服务和退出选择 |

这些是需要形成制度的事项，不是一份已经生效的组织章程。本页不预定席位数量、投票权重、任期、固定拨款或某一种法律登记方式。

## 与开放交付和数据权利的关系

共同治理应围绕能够清楚说明的公共基础与授权范围推进。公开讨论和生态资助不会把私有资料自动变为公共财产，也不会扩大对作品、会话或训练资料的许可。代码开放范围按实际发行和许可处理，见[开放组件](open-components.md)及 [RIGHTS.md](../RIGHTS.md)。

银河的网络自主性也需要保留：官方公共入口是可选发现与服务入口，第三方 Hub 可以按协议组织自己的网络，当前有限互联仍按具体范围执行。基金会或理事会的讨论不把官方服务变成所有查询必经的根节点，详见 [Hub 与官方](ecosystem-and-hubs.md)。

## 现在可以怎样参与

当前使用[贡献与反馈入口](../CONTRIBUTING.md)提交实际问题、改进和可公开讨论的建议。有关共同治理、激励和资助，可围绕具体场景、需要维护的公共资源和可持续成本提出意见。

后续只有在组织、规则、经费与执行条件确定后，才能把方向稿更新为正式治理文件或具体资助计划。项目阶段继续见[当前状态](status.md)。
