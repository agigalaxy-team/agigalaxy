# 主动查询反馈与本机汇总 v2

2026-09-10：C11-07 的本机实现。反馈是当前用户主动表达的个人意见；真实用户相关性、实际来源和宿主人工验收仍按原执行计划保留。动态 Official 服务未部署。

## 用户入口

分类型搜索的 Case、History、Proof、Capsule、Worker、Hub 详情均可打开“填写本机反馈”。“是否相关”和“是否帮助选择”独立选择，点击“保存反馈”才落盘；查看、返回、取消和点击结果均不计为反馈。可移除此条反馈。

“本机反馈汇总”出现在分类型搜索首页、绑定/审计/数据管理页以及读取服务信息之前的离线入口。重启或断开连接后仍可查看和修改已有意见，不需要重新绑定、读取 Manifest 或发送网络请求。

## 记录与统计

- v2 记录包含当前本机身份、所选端点、查询条件、来源类型/ID/版本/摘要、相关性、是否帮助选择、修改版本和更新时间。
- Case/History 使用来源事件版本与投影摘要；Proof 使用 Observation ID；Capsule 使用准确版本 ID；Worker/Hub 使用 Declaration ID。只保留来源引用和摘要，不另存搜索结果正文。
- 同一身份、端点、条件、来源类型和对象重复反馈覆盖原意见；分页游标和页大小不制造新反馈。Case 和 History 的反馈保持各自来源类型。
- 旧 v1 履历反馈兼容只读；主动修改后转为 v2。修改必须匹配所选记录的 revision，防止旧页面覆盖新意见；移除后重新统计。
- 汇总按当前本机身份和所选端点统计，可筛选来源类型。分别显示相关/不相关/不确定、有帮助/没有帮助/未回答、去重来源和条件数量。统计覆盖所选范围全部已保存意见，明细每页 8 条。
- 统计没有点击率、成功率、跨用户排名或能力认证效果。未记录意见的查询不进入分母；结果视图保留 `verificationEffect: none` 和 `sourceValidity: not-rechecked`，个人意见不表示来源目前仍有效。
- 读取时只统计本身份、端点范围内的有效记录，损坏记录显示排除数并保留原数据。存储复用本机状态锁，总条目上限保持 10000。

## 接口与生命周期

便携控制器通过可信宿主注入的 `saveSearchFeedback` 保存当前页反馈；本机文件实现不打入便携客户端。控制器绑定查询期间的身份和会话，取消、切换查询或替换会话后不能保存旧页面动作。本机运行时在写锁内再核对当前身份和配置，使用已有锁避免嵌套读取死锁。

本机运行时和显式配置入口提供：

```js
await controller.querySearchFeedback({sourceType: 'proof', limit: 8});
await controller.editSearchFeedback({id, revision, verdict: {
  relevance: 'relevant', helpedSelection: true
}});
await controller.editSearchFeedback({id, revision, verdict: null});
```

这是本机接口，不增加远程收集 API、默认遥测或用户总体分析。任何未来跨用户汇总仍需单独的数据用途和授权设计。

## 验证、部署与回退

针对性检查覆盖四类记录、去重、分页、旧数据、统计排除、修改冲突、取消/迟到动作、原生反馈表单与离线入口，并通过真实本机签名、Case 发布、查询、反馈及断开后的管理流程。HTTP 服务由隔离夹具提供，不表示生产已经运行。

反馈本身不增加 SQL 表，本机意见不自动进入远程导出。初次反馈汇总交付记录为 `GALAXY_SEARCH_FEEDBACK_SUMMARY_PROGRESS_2026-09-10.json`；后续 Worker/Hub 扩展记录见 [建设者来源搜索](builder-source-search-v1.md)，当前为 Schema33/41 表/30 本人云端导出集。AI Agent 部署时沿用显式 `dataDirectory` 和 endpoint 配置，不自动发现用户身份或远端服务。

如需回退，关闭反馈入口及宿主保存回调，保留本机原数据。旧版只识别 v1 的汇总程序不能直接读取新的 v2 记录；不要为回退删除反馈，也不要把只支持旧来源的程序当作完整替代。当前 v2 读取器继续兼容旧记录。
