# 当前实现文档导航

全部银河工作按[项目工作规则](../../../../02-architecture/current/WORK_RULES.md)实际读取要求、核对来源与完整业务语义，并沿生产者和消费者检查实际影响；不因进入工程目录就将范围限定为接口或UI。

产品要求统一从[当前大方案](../../../../02-architecture/current/GALAXY_COMPLETE_PLAN.md)、[体验规则](../../../../02-architecture/current/EXPERIENCE_RULES.md)和[逐界面目录](../../../../02-architecture/current/UI_SURFACE_CATALOG.md)读取。当前执行范围查[最新要求](../../../../01-intake/CURRENT_USER_REQUIREMENTS_2026-10-09.md)及[执行边界](../../../../99-index/ACTIVE_DEVELOPMENT_GOAL.md)，不以历史交付授权覆盖新的阶段要求。

旧版本说明中有用的协议、数据和检查内容集中在[技术参考索引](TECHNICAL_REFERENCE_INDEX.md)。原路径只作导航，不再保存另一套当前产品流程。旧文字中的“当前行为”、模块编号、菜单、部署指令和验收结论必须按其时间与版本解释。

[后续准备](../../../../02-architecture/current/RECONSTRUCTION_PLAN.md)明确保留能力与修改流程；[客户端规范](../../../../02-architecture/current/CLIENT_EXPERIENCE.md)和[官网内容](../../../../02-architecture/current/PUBLIC_CONTENT.md)覆盖用户说明。版本绑定的Skill、打包说明、许可与已发布文档保持原件，实际改进后再同步准确版本。

技术参考解释实际接口和历史数据；当前功能与流程按用户目的确定，不能从已有字段直接推导用户操作。

[文档处置表](../../../../02-architecture/current/DOCUMENT_COVERAGE.md)登记本轮每份资料的去向，历史原件见[归档](../../../../02-architecture/current/ARCHIVE.md)。
