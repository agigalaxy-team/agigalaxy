# 宿主进程内会话与断开边界

`createSessionMemory`接收完整连接结果的一次性凭据，并由宿主提供isCurrent回调检查当前本地身份、端点、scope意图与撤销状态。它不读取文件、初始化身份、访问网络或持久化凭据。输入必须来自本机已验证连接流程，不能直接采用网络JSON伪造的会话。

adopt按端点保存短期会话，最长600秒，默认最多32个端点；替换同端点会话会清除旧凭据。容量拒绝发生在提取凭据之前，不会意外耗尽调用者的一次性结果。宿主可按明确生命周期forget/close释放记录。

status只返回公开元数据，状态session-local表示本机暂存凭据，connected始终为false、remoteState为not-checked；不能据此显示“服务器在线”或“远端授权仍有效”。readAuthorization仅供可信Consent客户端/宿主组合回调，不可注册为普通MCP工具或写入日志。

每次读取检查当前时间与isCurrent；本地撤销、主体/目标变化、检查失败、过期、时钟倒退、disconnect、remote-rejected、remote-outcome-unknown或local-reset均可丢弃凭据。异步检查完成后核对原记录是否仍是当前记录；旧检查不得恢复已替换或清除的凭据。

可信宿主接线顺序：确认连接→完整握手结果→vault.adopt；Consent客户端readAuthorization从同一vault读取；用户断开/本地重置/远端拒绝调用invalidate；宿主退出调用close。网络超时或未知结果应清除本机凭据并显示需复核状态，不自动重试绑定或从磁盘恢复旧授权。

这一步只提供会话管理组件，尚未修改原生/galaxy页面或完成事件接线。进程重启后会话丢失，当前没有自动重连或操作系统钥匙串持久化；JavaScript字符串不能保证内存物理清零。已返回给可信调用者的副本也无法由此撤回，服务端事务仍须独立检查撤销。

测试覆盖状态不泄露凭据、scope副本隔离、过期后不因时钟回退恢复、迟到检查与forget/replace/invalidate/close竞态、容量拒绝及远端拒绝状态。连接客户端HTTP测试进一步把真实握手结果交给vault，读取所得凭据由服务端认证，再本地断开确认不可读取。

独立客户端构建新增`@galaxy/client/session-memory`导出，当前构建15个源码模块，仍只有3个依赖。较早14模块/4入口的tarball保留为历史，不作为新接口验证证据。
