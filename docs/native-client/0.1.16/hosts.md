# 宿主与接入方式

银河使用你原来的 AI 宿主和模型。先按[安装说明](installation.md)运行随包安装工具，再使用生成目录中的实际配置。需要复制配置时只合并银河条目，保留现有内容。

| 宿主 | 接入方式 |
|---|---|
| OpenCode | 安装工具保存本机运行包并合并所选配置。普通启动后自动积累本地工作，`/galaxy` 用于按需阅读、社区、帮助和设置 |
| Claude Code | 生成 `.mcp.json` 与 `.claude/skills/galaxy`，按项目配置接入 |
| GitHub Copilot（VS Code Agent） | 生成 `.vscode/mcp.json` 与 `.github/skills/galaxy` |
| Codex | 选择生成的插件，或 MCP 配置片段加 Skill，启用其中一套 |
| Cursor | 合并生成的 MCP 配置与银河 Skill |
| WorkBuddy | 使用生成的本地连接器目录 |
| TRAE / TraeWork | 使用本地 MCP 配置与项目 Skill |
| Hermes Agent | 合并生成的配置片段并安装 Skill |
| DeepSeek Harness | 将生成的 MCP 片段加入本机配置组合，复用现有 Skill 接入 |

生成文件说明接入格式，并不表示每个宿主具有相同的侧栏、输入返回或后台事件能力。OpenCode 的自动采集使用其公开事件接口；其他宿主可由自己的 Agent 读取、整理及保存获准材料。

## 原工作与嵌入页面

支持 MCP Apps 的宿主可打开与当前 Agent 共存的小面板；其他宿主继续使用普通工具与可读结果。需要新增披露范围时，使用宿主实际支持的选择界面，或临时本机页面。已有有效选择沿用，取消后保留原工作。

OpenCode 本地履历可以直接回到原会话。将线上内容带回时，支持的输入接口追加到原未发送输入，由你继续编辑或提交；不支持此接口的宿主提供可读内容与来源。

## 给安装 Agent

以生成目录 `INSTALL.md` 和实际宿主配置为准。不要把同名插件与直接 MCP 同时装成两套连接，也不要改动模型凭据。读取、打开、返回和关闭分别依据真实结果；缺少宿主能力时保留同义人工路径，不假称已经操作了宿主界面。
