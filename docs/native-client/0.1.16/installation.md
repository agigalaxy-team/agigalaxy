# 安装银河客户端

在原来的 AI 宿主中查找帮助、阅读资料和接续工作。OpenCode 还可以自动积累本地工作记录，由你在宿主中选用的模型整理。需要 Node.js 22.13 或更新版本；客户端不安装或替换 AI 宿主。

## 下载与安装

下载[安装包](https://agigalaxy.org/downloads/native-client/0.1.16/galaxy-native-client-0.1.16-install.zip)并解压。包内已包含客户端、核验材料与核验程序，无需分别下载。

在该目录运行：

```text
node verify-native-client-download.mjs .
tar -xzf galaxy-native-client-0.1.16.tgz
cd package
npm ci --ignore-scripts
node setup.mjs https://agigalaxy.org
```

核验程序按银河发行公钥检查下载，失败时保留现有安装并核对来源、版本和系统时间。安装工具从官网公开配置取得服务地址与公钥，在同一次选择中显示实际宿主、配置目录、资料位置和记录方式。

## 在 OpenCode 中使用

一次同意后，安装工具保存运行包、合并银河自己的接入条目，保留其他插件与模型设置。已有银河身份和类型继续使用；没有身份时准备个人身份，组织用途可在同一次选择中指定。以后照常启动 OpenCode，无需保留下载解压目录，也无需先打开银河菜单才记录工作。

普通文字和工具工作保留本地事实、来源、有限片段及主要环境版本。自己的模型增量整理；模型暂不可用时，事实仍然保存。需要回看时，在 `/galaxy` 打开“本地工作履历”，阅读记录或回到原会话。

上传预设“履历概况”。安装不关联线上账户，也不启动资料上传；完整会话默认不另存。需要同步或保存完整会话时，在“数据与隐私”选定账户和实际范围。四档及本人资料管理见[使用说明](runtime.md)。

## 其他宿主与自定义位置

其他宿主按生成目录的 `INSTALL.md` 合并对应配置，保留已有设置。不同宿主的可用交互见[宿主说明](hosts.md)；OpenCode 自动采集不能直接套用于其他宿主。

OpenCode 使用不被普通启动加载的自定义配置目录时，可以使用生成的 `run-opencode.mjs`。高级安装参数为 `--host opencode`、`--data-dir` 和 `--opencode-config-dir`，路径使用本机绝对路径。

## 升级与移除

升级时使用新发行包，继续选择原资料目录。保留旧可用包，不为升级重新创建身份。移除宿主中的银河接入不会自动删除本地资料、线上副本或撤销设备；这些操作在对应设置完成。

## 给安装 Agent

先读取本机 Node 与宿主位置，使用用户所选官网及当前发行公钥，再运行随包 `setup.mjs`。沿用已有授权完成安装，不覆盖无关配置，不把令牌、私钥或恢复材料写进插件配置。公开配置不可用时说明实际问题，不猜另一个服务或更换信任。

安装后读取当前身份和本地状态，按实际宿主能力打开相关内容并返回原工作。安装、工具加载、模型执行和业务结果各按实际发生情况判断，不把工具发现当作功能完成。
