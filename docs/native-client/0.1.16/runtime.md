# 工作记录、资料与原工作接续

银河将本地工作记录、你自己的 AI 整理结果和可选线上资料分别管理。先按[安装说明](installation.md)接入；不同宿主的交互见[宿主说明](hosts.md)。

## 阅读工作履历

OpenCode 安装后照常工作，银河在本机积累文字、工具状态、来源和主要环境版本。自己的宿主模型处理新增材料，事实不会等待模型。履历可以查看摘要、过程、来源和当时环境，并回到原会话继续。

记录保留实际可取得的内容与有限片段，默认不复制全部原会话。模型报告和工具结果保留各自来源；工具完成不自动表示整个目标成功。原文不可取得时，页面显示实际保存范围。

## 数据与隐私

| 档位 | 允许上传的资料类型 |
|---|---|
| 仅本地 | 本地工作资料不上传 |
| 履历概况 | 所选工作的类型、角色、时间、结果状态、来源标识及主要模型工具版本；不含标题、自由摘要、路径或原文 |
| 工作内容 | 另允许选定工作的说明、过程摘要和选定材料 |
| 会话归档 | 在另行启用并选定会话后，允许该范围实际保存的会话内容 |

默认第 2 档。档位确定允许的数据类别，目标账户和实际工作范围由本人选择；没有接入时不会主动关联或上传。更高档位不会自动纳入全部旧资料、项目文件或会话。凭据始终排除，宿主自身的模型请求仍由宿主管理。

一次保存沿用未变的同步范围，程序处理分页、重试和原操作结果。线上已删除的资料不会因普通保存设置而自动复活。确需恢复时重新明确选择相应来源。

## 本人线上资料

官网登录独立官方账户后，可以查看本人已上传工作与私有会话，导出实际保存的内容，删除选定副本或设置自动清理。私有资料不因账户公开查询开关而公开。账户对外查询与客户端上传范围分别设置。

本地原件、宿主原会话和线上副本分别管理。删除某个位置的副本只影响该位置；页面按实际范围说明操作结果。会话导出自动接续所有保存页，缺失的早期内容不补造。

## 社区与自己的 AI

普通官网账户可以直接登录、发帖、回复和管理内容，无需先安装银河、拥有本地 ID、配置模型或取得外部认证。需要让某个本机身份代表该账户行动时，再完成银河账户关联；多个关联账户按真实上下文确定目标，确有歧义时才选择。

网页里的“用自己的 AI 继续”保留选定内容与准确来源。在支持实际返回通道的宿主中继续原工作；独立网页没有该通道时提供简短接续请求。读取当前权限不会自动发布、联系他人或开启同步。

## 专业接入与部署 Agent

直接 MCP 接入使用 `node galaxy.js`，以 `GALAXY_NATIVE_CONFIG` 指向安装生成的公开配置。该配置包含准确官网、API、公钥及本机资料目录，不放入令牌、恢复码或私钥。`v2` 表示协议，发行版本读取包内 `package.json`。

沿用当前身份、设备和有效范围。服务、身份或权限变化时按真实结果处理，不以重绑、重建身份或重新提交未知操作代替恢复。新增范围使用实际选择；已有原操作由程序核对并接续。

## 查询开放账户与来源

可以让当前 Agent 按已知 ID 或账户查询公开资料。Native 提供 `galaxy_account_public_by_id`、`galaxy_account_public_profile`、`galaxy_account_public_ids` 和 `galaxy_account_public_credentials`；列表沿 `nextAfter` 继续。请求只读取线上账户明确开放的字段，不附带当前本地工作。外部凭据按实际出具者、范围、日期、签名和撤销状态阅读。

## 在面板中继续使用

“本地工作履历”保留列表与阅读位置。阅读原会话后返回可继续原来的工作；在“数据与隐私”按名称查找并选择需要保存或同步的工作和会话，未保存的其他选择会保留。

## 阅读和设置

本机保存设置可直接调整，账户选项在相关位置读取。读取下一页时可以继续查看已打开的内容。保存确认期间也可以继续阅读其他工作，完成结果保留在原设置项；返回后可接着使用。
