# 状态与发行信息

银河处于 Beta 持续开发阶段。当前有网站、Hub、运营管理、后台 Native 和用户端客户端的实际实现，各自按准确发行与使用范围判断。

维护者记录的带日期发行观察、本地整合候选、尚未完成事项及旧公开入口/CI 记录统一见[项目状态与版本边界](project-status.md)，本页不另维护第二份版号表。实时公开信息从[官网状态](https://agigalaxy.org/status/)和[发行核验材料](https://agigalaxy.org/downloads/verification/)读取。

客户端下载、安装与真实宿主边界见[开始使用](getting-started.md)和[0.1.19随版指南](native-client/0.1.19/installation.md)。用户端模型仍来自原有宿主，后台运营引擎是独立范围；运行完成、业务成功、答案质量与长期效果分别表达。

愿景、现有实现、开放交付与制度候选见[项目架构](vision-and-architecture.md)、[Hub运作](ecosystem-and-hubs.md)、[开放组件](open-components.md)和[共同治理](community-governance.md)。发现资料与行为不一致时，可在[公开Issues](https://github.com/agigalaxy-team/agigalaxy-public/issues)提供准确页面、版本、宿主和可公开的复现步骤，不上传私聊或凭据。
