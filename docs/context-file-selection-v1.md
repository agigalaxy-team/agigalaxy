# 本地文件与日志片段选择

2026-09-10，C06-05 本地实现。它将用户选定的文件行转换为已有的 Context 文本材料；远程接口、数据库和本地草稿格式保持不变。

## 使用流程

1. 已确认协作中的“授权选定文本材料”提供“粘贴文本片段”和“选择文件或日志片段”。既有材料草稿可添加文件片段，也可在某个材料菜单中选择“从文件或日志替换片段”。
2. 用户输入绝对本地路径及明确的起止行号，如 `12-24`；单行写 `12-12`。不默认选取整个文件，不遍历目录、不跟随 URL，不打开网络共享。
3. 原生预览显示文件路径、行号、生成的材料名称和完整选定文本。返回确认菜单后，只有选择“加入本地草稿”才保存。取消、迟到回调和旧草稿版本不会覆盖已保存材料。
4. 草稿仅保存可编辑的名称和选定文本；默认名称为文件名和行号，绝对路径不进入草稿、提交日志或远程载荷。编辑名称可去掉文件名。替换片段保留材料 ID，新增片段产生新 ID。
5. 文件导入后是一份固定文本副本。源文件之后修改或删除不会改变草稿，重启后也不自动重读文件。用户可以再次明确选择并预览新片段。
6. 在线和离线的可信宿主入口均支持本地选择。在线发送仍经过准确接收方、范围、期限和全部材料预览、本机签名及指定提供者独立接受；导入文件本身不提交或授权远程访问。

## 当前支持范围

支持最大 8 MiB 的普通 UTF-8 文本文件，每次明确选择 1 至 200 行，选定正文最多 4000 字符。UTF-8 BOM 不进入正文，CRLF、CR 和 LF 统一为 LF，末尾换行不额外算一行；范围越界、空片段和超限均提示重新选择，不截断或自动扩展。原有每份材料 1 至 8 段、总载荷 16000 字节的限制继续适用。

预览只在内存中读取一份有大小上限的本地文件；读取期间尺寸或修改时间变化会要求重新预览。已知凭据文件名和目录在打开前拒绝，所选文本复用现有凭据格式检测；二进制、无效 UTF-8、终端控制内容、符号链接和目录不支持。此检测不保证识别所有秘密，不会静默改写或脱敏材料。测试仅使用临时合成文件。

绝对路径、捕获时间与片段 SHA-256 只属于本次本机预览，不构成服务器来源验证、Evidence 或能力证明。既有远程读取审计、撤销、当前范围检查、所有者导出和删除继续适用于提交后的文本材料。

原始完整 Context 自动上传、目录扫描、任意远程文件读取、对象存储、端到端加密、Shell、仓库写入和生产访问不属于该入口。生产保留期限与存储部署继续由 C00/C18 的既有任务处理；高风险访问仍按独立阶段实施。
