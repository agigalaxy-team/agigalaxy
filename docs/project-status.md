本页记录 2026 年 10 月 21 日整理 GitHub 资料时的观察。版本会继续变化，带日期的观察不代替当前运行状态；完整源码、网站、API、客户端、文档与数据库分别版本化。

## 目前是什么阶段

银河有实际官网、业务网页、Hub 实现和可下载的 Native 客户端，处于 Beta 持续开发中。当前仓库同时包含已发行能力和后续候选，不能把整个 main 当成一个已经完成全面验收的安装包。

| 范围 | 已有基础 | 仍需分别核实 |
|---|---|---|
| 官网与网页 | 项目介绍、发现、社区、账户、对话、工作、人物、方法及公开说明 | 非空真实业务、当前依赖及受影响流程 |
| Native | 0.1.16 公开安装包，MCP / 小面板 / 宿主配置、本地身份和工作资料 | 全部物理宿主、版本组合、真实模型和长期运行 |
| Hub 服务 | PostgreSQL 业务、权限、签名、工作事实、来源及协议适配 | 与准确发行对应的业务链和外部服务 |
| 运营管理 | Payload / Next.js 应用、独立管理认证、部分业务治理和发布候选 | 已讨论的完整运营范围、实际激活与逐项能力 |
| 监控与恢复 | 运行工具、日志、告警及 restic / pgBackRest 编排 | 当前接收人、备份执行、隔离恢复、整站恢复及异机恢复 |
| 深入运营与 AI | 已讨论跨模块分析、画像、推荐、辅助治理及策略自动化 | 引擎选择、具体规则、实现和实际效果；尚不是已交付完整后台 |

用户端自己的模型接入与运营后台 AI 是两个范围。Agno / AgentOS、LangGraph / Deep Agents 等是研究候选，不能标成当前部署的技术栈。

## 文档可移植性

此前多处文档链接依赖仓库外的本地项目目录，GitHub 和独立克隆无法访问。当前主入口改用仓库内项目概览、架构、下载、开发和部署说明。部分历史技术正文只保存在维护工作区，导航应明确其未随仓库分发，不能假装读者能够打开。

历史记录继续按原版本解读。旧浏览器 ID 流程、过期下载、旧宿主验证和早期服务状态不能覆盖现行账户参与与客户端说明。

## 产品介绍需要保持的区别

网络的帮助、项目与机会、交流、协作和方法使用，应在介绍中先讲清楚。身份、履历、资料、来源与协议支撑这些活动，不能用它们替代网络功能。客户端的大部分交互围绕原模型聊天继续，不能将资料组合、引用定位等底层处理推导成普通用户必须手工完成的流程。

官网现有部分展示以资料组合和出处交互为中心，容易产生上述误解；相应展示仍需单独修订与发布。本次 GitHub 文档修正不代表已经修改线上页面。具体功能及源码边界见[网络功能](network-functions.md)。

## 后续方向

继续完善实际宿主接入、外部依赖整链、资料与发行一致性、工程诊断以及完整后台运营。后台的自动规则、AI 决策、人机协作与人工接管仍需按已讨论范围逐项落实；不从一个框架名称推导完整系统已经实现。

线上分组实验和模型离线样本评测等未选能力不能因增加 AI 自动成为承诺。实施范围以项目的实际决定与可核验交付为准，不以 README 的模块目录当作功能完成清单。
