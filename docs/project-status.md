## 2026-10-26 的发行观察

项目维护记录在 2026-10-26 08:30（Asia/Shanghai）重新确认 API **0.1.105**、管理端 **0.1.107**、运营 Native **r36**、数据库 **schema131**。Web **0.1.100** 沿前一批最终发行记录，CMS 未随本批更换。这是相应时点的维护观察，不是源码克隆时的实时健康检查。运营 Native r36 与公开用户客户端 0.1.19 是不同产品及版号。

运营管理已实际采用 Payload/Next.js、独立 Keycloak 管理认证、PostgreSQL/pg-boss、Agno/AgentOS Native 及私有模型网关。工作台、五个 AI 工作账户、角色与权限交集、提示词管理、查询与操作卡、有限自动任务和审计来源已有核心实现及实际发行。Agno/AgentOS 不能再写成仅有研究稿；框架接入同样不能代表整个运营计划已完成。

本次仓库收束保留原提交、精确发行增量与逐路径来源，恢复必要消费者、构建材料和维护源码。新增 Gateway 诊断、备份保留及恢复适配器等本地提交没有因此重新部署。生产恢复配置入口仍拒绝开启，暂停的 migration120 仍未注册；历史 SQL 不重写。

本地候选已区分停止征集与整单终止，使用现有接口表达明确终止意图；兼容细节属于本次实现，后续可按实际消费者演进，不列为通用开发规则或仓库整理的审批前提。远端整合和正式运行按维护者当次授权办理，源码包与已部署状态分别说明。构建边界及尚存源码耦合见[组件目录](component-catalog.md)，实际配置发现见[部署说明](deployment.md)。
