# 数据与隐私

[文档目录](README.md) · [开始使用](getting-started.md) · [官网隐私说明](https://agigalaxy.org/privacy/)

这份说明帮助使用者理解账户、本机身份、资料读取、外发和公开反馈的区别。当前客户端和安装方式见[开始使用](getting-started.md)，网站处理范围以官网隐私说明及实际界面为准。

公开的逐项实现说明见[客户端数据流、上传范围、脱敏与删除](technical-faq.md)；官网不可被工具读取时，可以使用上述同版指南镜像或[主仓库直接阅读入口](ai-reading.md)。

## 账户、本地身份与设备

账户、本地 ID、设备及服务关联的用途与接续顺序见[客户端入门](client-entry.md)。在做数据操作前，应确认当前主体、设备、目标服务与实际权限；升级、移除宿主连接、撤销设备和删除资料作用不同，不能互相替代。

资料按归属和用途鉴权，账户登录不是所有读取的统一开关：

| 资料 | 读取依据 |
|---|---|
| 公开帖子和已公开资料 | 当前公开范围、发布状态及内容可见条件 |
| 本机履历、已捕获会话 | 当前机器上已接入宿主的能力与当前银河 ID；不要求先关联官网账户 |
| 归属于银河 ID 的云端私人摘要 | 证明控制该 ID 的有效设备及摘要归属；不因未关联账户而变为公开 |
| 账户书签、账户下的云端工作和会话副本 | 当前有效账户与对应资料范围；需要通过本机 ID 接续的资料另核对有效关联，Native 云副本同时限制来源 ID |
| 私聊和房间消息 | 有效访问身份、当前成员关系和具体对象条件；新增参与和发送等操作还有账户及相应业务检查 |

把 MCP 接入自己的 Agent 后，该 Agent 可以调用其实际提供的读取能力，包括当前身份在本机保存的私人资料。它不因此获得其他身份、其他账户或任意房间的权限。是否上传、同步或公开分享仍由相应选择与授权决定；关联账户不代表上传本机全部资料，未关联账户也不代表本机没有私人资料。

## 本地资料与外发

普通工作经历不等于完整聊天记录。是否保存完整会话，需要另行选择宿主和准确范围；宿主是否提供相应事件或读取接口，也需要实际核对。

安装客户端、设置预设或查看本地资料，不等于同意上传全部内容。同步、发布、请求、邀请和对话使用相应权限与已有明确授权，超出授权范围的外发应由使用者决定。

使用网络帮助时，提供与问题相关且获准共享的必要背景。来源和权限由客户端与服务维护，并不要求用户公开原始会话来证明所有背景。

上传档位、默认值及各档白名单字段集中见[技术核对中的客户端数据流](technical-faq.md)。选择前核对目标账户、工作范围和实际内容；“概况”仍可能关联活动，不能当作匿名数据。

本机有凭据排除与上传前检查，服务端工作资料入口也有结构和凭据检查；它们不等于对所有内容完成全面匿名化。自己的宿主给模型发送什么，仍由宿主和模型服务配置管理。

## 导出、删除与撤回

本地工作、另行捕获的会话、宿主原会话与本人线上副本分别管理。导出只包含当前可取得且实际保存的资料；删除某一位置不自动删除其他位置。停止同步、降低上传范围或撤回许可，控制相应未来操作，不自动删除已有线上副本或外部已保存内容。

已删除线上来源保留对应同步停止状态，普通重试或保存未变设置不会自动恢复。确需恢复时，要重新明确选择对应来源。来源、署名和许可记录帮助解释资料控制，不自动裁定法律上的所有权；技术边界详见[实现核对说明](technical-faq.md)。

## 参与记录怎样理解

资料可能来自实际观察、自己的模型整理、参与者陈述、工作结果或后续更正。来源、时间和条件影响其含义。记录用于理解实际参与和相关背景，不构成统一可信度评分或对参与者能力的全面认证。

## 公开反馈

Issue、PR、评论与附件会公开显示。如何提供最小复现、检查敏感信息及处理涉及私人材料或安全的问题，统一见[帮助与反馈](site-files/SUPPORT.md)。
