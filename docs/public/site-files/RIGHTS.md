# 公开资料与许可范围

本仓库公开银河项目介绍、功能图示、公开网站截图和用户指引，供阅读、了解项目及提交公开反馈。核心实现、内部部署资料和私有开发历史不在本次公开范围内。

公开可访问与授予统一开源许可是不同事项。本仓库当前没有为全部材料声明统一的 MIT、Apache 或 Creative Commons 许可；不要从仓库可公开访问推定这些许可已经适用。对外再分发、改编、商业使用或其他授权需求，请与材料权利方确认。

客户端下载页提供的独立发行物，按发行包内的 LICENSE、NOTICE 及随版声明适用范围处理。本资料仓库不扩大或替代客户端及第三方组件的许可。

已核对许可的历史 Native 0.1.16 发行，其选定 Galaxy 自有代码、Skill、集成辅助工具和随包文档按 Apache-2.0 提供，第三方组件维持原许可。该范围不覆盖整个核心仓库、用户资料或未发行服务；原始开放模块规划和当前实际交付见[开放组件说明](../open-components.md)。

文中出现的产品、协议及第三方项目名称用于说明技术采用与兼容关系，不表示相关项目为银河背书。截图用于展示相应时点的公开页面，示例内容及当前实际服务以网站标注为准。


本组资料同时保留 Native 0.1.19 开发候选的指南。其许可仍按该准确发行包的 LICENSE、NOTICE 和随版声明核对；0.1.16 的核对不自动构成 0.1.19 的重新法律核验。本次文档整理没有改变任何组件许可。
