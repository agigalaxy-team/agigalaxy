# 参与公开资料维护

欢迎纠正文档、改进使用说明、翻译和提供可复现反馈。公开资料唯一正文在主源码仓库的 `docs/public/`，本仓库的文件由显式清单生成；不要分别维护两份正文。

## 提交问题和修改建议

通过公开 Issue 说明具体页面或版本、目标、预期和实际结果。纠错可附公开出处，使用问题提供最小复现。无法访问主源码仓库的贡献者仍可在本仓库提交 Issue 或 PR；维护者先把采纳的修改归入唯一正文，再重新生成公开镜像。

维护者在主源码仓库按 `docs/public/PUBLISHING.md` 检查并同步。文案修正不要求产品构建；受影响的链接、图片、版本和来源一并核对。公开同步在本地生成，提交、上传和发布按另行授权进行。

## 材料范围

适合提交介绍、翻译、用户指引、公开示意图和有权公开的截图。核心源码、内部设计、原始讨论、部署配置、运行记录和真实用户资料不进入公开同步。尚在设计或局部验证的能力按实际范围表达；历史观察不写成永久现状。

Issue、PR 和附件会公开显示，先检查隐私与凭据，见[帮助与反馈](SUPPORT.md)。许可范围见[RIGHTS.md](RIGHTS.md)。
