# 帮助与反馈

| 问题 | 建议入口 |
|---|---|
| 想了解银河与如何参与 | [项目介绍](README.md)、[网络功能](../network.md)、[官网文档](https://agigalaxy.org/docs/) |
| 客户端下载、安装与宿主兼容 | [开始使用](../getting-started.md)、[官网下载页](https://agigalaxy.org/downloads/)及对应随版指南 |
| 查看公开服务信息 | [官网状态页](https://agigalaxy.org/status/) |
| 文档错误、可以公开讨论的使用问题和建议 | 本仓库 [Issues](https://github.com/agigalaxy-team/agigalaxy-public/issues) |
| 修正文档或翻译 | 按 [CONTRIBUTING.md](CONTRIBUTING.md) 提交 PR |
| 账户、私人内容或涉及敏感材料的问题 | 先从[官网](https://agigalaxy.org/)寻找适当的业务或联系入口 |

反馈时提供公开页面、所用版本、宿主、最小复现步骤、预期行为和实际结果即可。文档与版本不一致时，请注明观察时间，便于区分资料过期与实际故障。

Issue、PR、评论及其中的附件会公开显示。上传前检查截图、URL 和日志中是否含有密码、令牌、私钥、恢复材料、邮箱、私聊内容或未公开的项目资料。无需为普通反馈公开完整会话或整个本地目录。

疑似安全问题不宜直接附上可利用细节、凭据或真实用户样本。先通过官网提供的适当联系入口确认接收方式；本仓库没有承诺专用私密安全受理渠道或响应时限。
