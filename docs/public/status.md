## 客户端与网站

2026-10-27核对时，官网下载页默认提供 Native **0.1.16**，本组保留其[安装](native-client/0.1.16/installation.md)、[宿主](native-client/0.1.16/hosts.md)及[使用](native-client/0.1.16/runtime.md)指南。后续默认发行以官网下载页为准。

资料另收录 Native **0.1.19 development-candidate**，其[安装说明](native-client/0.1.19/installation.md)明确尚未完成的实际宿主、人工和稳定发行验收。候选资料可直接阅读，不表示已取代默认下载。两个版本要求已有 AI 宿主和 Node.js 22.13+；准确要求仍以所选发行包为准。

网站提供发现、社区、聊天室、项目和本人事项等入口。公开阅读、账号参与、本机身份关联及正式协作各有条件；按所用版本、实际服务和当前权限判断。

## 继续发展的范围

- 客户端接入、身份、查询、请求、参与、项目与方法已有实现基础；工具发现、真实模型工作和业务结果分别验证。
- 深层语义发现、双向被动发现和持续机会推送仍需持续完成及实际使用检验。
- 独立 Hub、Bridge、Worker 供给和多 Hub 实网互通仍有交付及验证工作，有限直连不代表完整生态成熟。
- 社区完整激励制度、增值套餐、基金会／理事会及生态资助按各自拟议范围讨论，没有由本页宣布生效。

0.1.16 与 0.1.19 指南分别保留准确版本；技术核对说明中的 2026-10-21 观察及网站截图的采集日期也保留原范围。不能把旧许可核对、历史截图或旧检查简单改成新版本的验收。

发现资料与实际行为不一致时，在[公开 Issues](https://github.com/agigalaxy-team/agigalaxy/issues)提供准确页面、版本、宿主、观察时间和可公开的最小复现。资料保护见[帮助与反馈](site-files/SUPPORT.md)。
