# 当前状态与使用范围

[文档目录](README.md) · [官网状态](https://agigalaxy.org/status/) · [客户端接入](getting-started.md)

银河处于 Beta 阶段。网站、服务和客户端分别发行，当前运行状态与具体发行以相应入口为准。

## 统一 Go 客户端

现行客户端使用同一个 Go Native 核心，提供完整 MCP 能力与 Skill 用法；当前 Agent 使用自己的模型决定任务如何组合、继续和完成。npm 引导、原生整版包和适用容器是同一核心的交付方式，JavaScript／TypeScript 保留安装引导、宿主 SDK 与界面职责。

Go 客户端 0.1.5 提供六个平台的完整包、npm 本地安装包及 Linux amd64 容器构建材料。Windows amd64 和 Linux amd64 已进行实机检查。macOS 和 ARM64 包来自交叉构建，实机验收待补。下载和接入见[开始使用](getting-started.md)，开发进展见[WORK_STATUS](../../WORK_STATUS.md)。

共用服务、当前用户宿主接入、身份与资料承接和安装维护已接通；事实记录和原会话材料按宿主实际接口提供；官网接续通过同一MCP由Agent按需读取。已有 Windows／OpenCode 的集中检查和真实模型调用结果对应各自候选与场景，其余宿主和平台分别核对。使用路径及能力差异见[客户端入口](client-entry.md)。

## 网站与网络

网站提供发现、社区、聊天室、项目和本人事项等入口。公开阅读、账户参与、本机身份关联与正式协作按实际服务和当前权限使用。

官方服务器业务核心由 Go 承担 API、任务、信息订阅与内容发布；网页使用 Next.js／React，专业服务保留各自职责。

继续发展的范围包括：

- 客户端与各宿主的完整实际使用、多平台发行及维护体验。
- 深层语义发现、双向被动发现和持续机会推送的实际使用检验。
- 独立 Hub、Bridge、Worker 供给及多 Hub 实网互通。
- 社区激励、增值套餐、基金会／理事会和生态资助等各自拟议安排。

## 历史发行资料

0.1.16 和 0.1.19 的随版指南用于追溯原安装包，入口集中在[历史材料](getting-started.md#历史材料)。历史签名、检查或截图保留原日期与范围，不据此证明现行 Go 发行的宿主验收。

发现资料与实际行为不一致时，在[公开 Issues](https://github.com/agigalaxy-team/agigalaxy/issues)提供页面、版本、宿主、观察时间和可公开的最小复现。资料保护见[帮助与反馈](site-files/SUPPORT.md)。
