# 安装银河客户端

本页对应开发版 0.1.19。客户端在原来的 AI 宿主中提供获准的资料、工作与协作，不替换宿主或模型。需要 Node.js 22.13 或更新版本。

## 下载与核验

下载[完整安装包](https://agigalaxy.org/downloads/native-client/0.1.19/galaxy-native-client-0.1.19-install.zip)，解压后在该目录运行：

```text
node verify-native-client-download.mjs .
tar -xzf galaxy-native-client-0.1.19.tgz
cd package
npm ci --ignore-scripts
node setup.mjs https://agigalaxy.org
```

核验程序使用银河公开发行公钥，检查签名、有效期和准确包内容。核验失败时保留原安装，核对来源、当前公钥状态和系统时间；不关闭校验或改用另一个身份。

## 安装到原来的工具

安装工具读取所选官网的公开 API 与公钥，显示实际宿主、配置目录、本地资料位置和记录方式。沿用已有银河身份和资料目录，保留其他插件、项目与模型设置。安装本身不注册账户、不关联服务，也不启动上传。

OpenCode 的普通接入与其他宿主的能力边界见[宿主说明](hosts.md)。本地记录、同步选择、退出与专业配置见[使用说明](runtime.md)。其他宿主按随包生成的安装说明合并自己的接入配置，不能据工具发现推断全部业务已经完成。

## 升级与移除

公开新下载不会自动更新已经安装的客户端。需要新版时主动下载、核验并运行安装，继续使用原资料目录，不为升级重新创建身份。保留原可用包，确认新接入后再切换宿主。移除宿主接入不会自动删除本地资料、云端副本或撤销设备。

## 发行范围

0.1.19 的正式准备记录通过四项签名 HTTP 合同与三项实际候选 stdio 合同，共七项必要发行检查，数据为本地合成材料；它们不代表所有真实宿主、真实业务、真人效果或稳定发行验收。本包仍为 development-candidate，actualHostAcceptance、humanAcceptance、stableRelease 均为 false。原始运行与宿主说明来自此准确签名包，保留其中历史验证的时间和范围。

## 给安装 Agent

先查看当前 Node 和宿主位置，用用户选定的官网与当前发行公钥核验，再使用包内 setup.mjs。已有授权和有效选择直接接续，不覆盖无关设置，不把令牌、私钥或恢复材料写进插件配置。公开配置不可用时报告实际问题，不猜另一服务或更换信任。安装、工具加载、模型执行和业务结果分别以实际发生情况判断。
