# 开放组件、开源复用与当前交付

[项目首页](site-files/README.md) · [愿景与架构](vision-and-architecture.md) · [Hub 与官方](ecosystem-and-hubs.md) · [资料使用范围](site-files/RIGHTS.md)

银河希望通过可检查、可适配的组件，让不同客户端、专业能力提供者、社区和企业参与同一网络语义。开放的意义包括检查本机数据处理、连接已有系统、运行自己的专业能力及自主组织 Hub。

需要分别看四件事：软件是否开放及采用什么许可、某项官方服务是否免费、增值服务是否收费、参与者之间是否另有报酬。它们不是同一个开关。

## 原始设计中的开放模块

下表中的名称是原始设计的逻辑模块名，**不是已经全部独立发布的包名或仓库清单**。当前实现可能合并在客户端、业务服务和适配代码中。

| 原设计模块 | 为什么开放、供谁使用 | 当前公开交付与差额 |
|---|---|---|
| `galaxy-core-spec` | 共同主体、工作、来源、方法和撤回等语义，让其他实现能理解数据 | 本仓库提供部分结构与技术说明；完整独立规范交付仍需整理 |
| `galaxy-sdk` | 为客户端和外部系统提供协议、结构与调用基础 | 已有客户端协议和集成基础；未在本仓库发布通用独立 SDK 套件 |
| `galaxy-edge-core` | 在本机接入工作环境，便于检查哪些资料保留和外发 | 选定实现随 Native 开发版公开；宿主实际支持深度分别核对 |
| `galaxy-worker` | 让专业 Agent 或工具在授权环境提供能力，按配置与策略参与 | 有 Worker／A2A／Pack 接入基础；完整自建运行、长期供给和全天执行需独立验证 |
| `galaxy-hub-core` | 企业、社区和服务提供者自主经营本地网络 | 有 Hub、章程、成员和有限互联实现基础；完整独立开源部署交付尚未完成 |
| `galaxy-bridge` | 让外部平台按明确来源和映射参与，减少整体迁移要求 | 有外部来源与映射基础；不据此宣称任意平台均可直接接通 |
| `galaxy-conformance` | 检查版本、结构、签名、许可和撤回等兼容行为 | 发行含相应核验和协议报告；完整独立兼容检查交付需按实际版本提供 |

首批 Pack 沿版本清单和外部来源引用理解，安装使用原发布方或宿主机制。它不等于新建一个已经可用的二进制包市场，也不因为安装就获得监控、资料访问或自动成交权限。

普通使用与自建服务的准备范围见[客户端入门](client-entry.md)。

## 复用成熟开源项目承担基础工作

银河复用认证、数据库、界面、通信和任务工具，具体依赖与用途由[技术栈](technology.md)集中列出。银河负责自己的网络业务语义、权限和适配；采用某个项目不表示它的全部能力都已经部署。

第三方组件保留各自许可、锁定版本和原始声明。Native 发行物的许可清单、服务组件的公开源码义务和本资料仓库的阅读范围分别处理；不能把选定 Galaxy 代码的 Apache-2.0 扩大成整个依赖栈的统一许可。当前可取得的交付物见本页前表。

## 开放协议、贡献者与持续维护

MCP 和 A2A 等是银河采用的接入与协作基础。银河希望把不同环境连接到持续的参与和知识网络，而非要求参与者为网络重建底层通信方式。长期开放还需要代码、文档、适配、社区及运行维护贡献，见[贡献激励](growth-and-contribution.md)。

由官方服务支持公共组织、由基金会或理事会支持开源生态，是新提出的共同建设方向，具体组织与经费仍待落实。开放愿景、真实许可和治理制度分别说明，见[网络宣言](site-files/MANIFESTO.md)与[治理方向](community-governance.md)。

## AI运营引擎与专门服务

运营后台已采用Agno/AgentOS3.1.7原生引擎，并接入OpenPanel分析、Gorse推荐、Meilisearch搜索和LiteLLM模型入口；银河提供统一页面、真实业务权限与动作。LangGraph.js/Deep Agents及大范围融合仍是备选，不能将全部研究项目列为实际采用。

这项建设复用现有业务能力和开源组件，具体模块、执行权限与界面继续按实际决定推进。用户端继续使用自己的 AI 宿主，运营后台引擎是不同范围。

## 继续参与

公开资料、反馈和纠错可从[贡献说明](site-files/CONTRIBUTING.md)进入。涉及专业能力、Hub、Bridge 或其他系统合作时，应先说明具体目标、已有来源、实际支持版本、授权及所需交付，再讨论接入范围。

原始开放模块设计是方向，当前许可和可取得的发行物是实际交付依据。开放代码不公开用户资料，读取作品不自动授权改编、商用或训练；按内容自身的权利与许可处理。
