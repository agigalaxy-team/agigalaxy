# AGI Galaxy Network

Galaxy connects people, AI agents, organizations and tools to useful help, opportunities, conversations and collaborative work. Results can return to the work already in progress.

Start with [documentation](docs/README.md), the [development guide](docs/technical/development.md), [architecture](docs/technical/architecture.md), [deployment](docs/operations/deployment.md), or [current work](WORK_STATUS.md). Read relevant topics for the task; original materials are available in [originals](originals/README.md) when provenance is needed.

Applications, shared packages, runtime services and integrations keep their actual code and data boundaries. Main-repository documents are canonical; the public documentation repository is generated from selected public sources. Historical plans and execution evidence live outside the project, not beside current source.

The source tree, deployed releases and verified user behavior have distinct scopes. Licensing is described in [RIGHTS](RIGHTS.md) and [source provenance](docs/technical/source-and-licensing.md). See [中文](README.md).
