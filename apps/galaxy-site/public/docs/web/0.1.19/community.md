# 浏览社区与找回收藏

本说明对应 Web 0.1.19、API 0.1.14 与 Native 0.1.11 开发候选的社区和内容发现功能。

## 按主题阅读

从[社区](/app/community)选择“技术与工具”“艺术与创作”“阅读与学习”“生活与兴趣”或“银河使用与反馈”，也可以浏览全部帖子。历史上没有选择主题的帖子保留在“未分类”，原正文和版本保持不变。

在当前主题输入关键词，可以查找标题和正文；清除查询后继续当前主题。继续加载会取得这个范围内较早的帖子。列表显示首次发布时间；详情中的编辑时间说明后续更新。

打开帖子后直接阅读和回复。正文末尾的“继续浏览”与页面返回入口会接回原主题或搜索结果，保留已加载条目和阅读位置。返回时来源仍按当前可见范围核对。

## 发帖与继续草稿

从一个主题进入写帖，会带入该主题。填写标题、正文及需要的关联内容即可发布；主题仍可在编辑处修改。已有草稿沿用原内容，登录、刷新和返回后继续，不因从另一入口打开而覆盖。

普通讨论、作品分享和兴趣交流都可以在社区自然结束。需要继续联系或请求帮助时，再从相关入口进行。

## 收藏后再读

帖子、方法、项目和人物资料可以“收藏”，在[我的收藏](/app/bookmarks)按内容种类回找，也能直接取消。收藏只对本人可见，同一身份下获准的其他设备可以继续读取；无需填写工作目的或开启持续关注。

方法保留收藏时选择的准确版本。系统只保存内容引用和本人的选择，每次打开重新核对来源。来源撤回、权限变化或暂时无法核查时显示实际情况，不用旧缓存冒充仍可阅读的正文。

## 浏览方法和项目

方法与项目可以不输入关键词直接浏览目录。在项目条目点击实际声明的功能，可以查找具有该功能的相关项目。加载后续条目、进入详情再返回时，会保留当前范围与位置。

搜索和收藏帮助找到内容；是否采用方法、联系作者或参与项目由本人决定，页面不会仅因浏览而发起工作。

## 在自己的 AI 中继续

Native 的“逛社区”入口和社区工具支持主题、查询、帖子正文与回复，普通收藏可与官网接续。模型按当前问题整理已获准内容，并给出来源。实际发送、发布或新增资料范围仍在对应动作中作出选择。

安装与验证见[客户端安装](/docs/native-client/0.1.11/installation.md)。0.1.11 的增量完成了菜单、真实本机 HTTP、网页接续和独立包协议检查；此前 OpenCode 1.18.31 的实体宿主操作记录属于 0.1.10，不代表所有新增功能已在每个实体宿主复验。

## 给接入 Agent 的说明

公开主题和帖子可以按当前公开接口读取；私有收藏须使用本人的现有身份、当前设备权限与有效授权。通过客户端的社区、收藏和打开工具传递准确来源，不要求用户抄写对象 ID。保留原查询与当前工作，只在实际范围改变时补充选择。

无法连接时保留查询和独立输入，网络恢复后重新读取。提交结果未知时沿原操作核对，避免重复发布。不要把收藏数量、内容曝光或有限经历解释为资格或通用能力证明。
