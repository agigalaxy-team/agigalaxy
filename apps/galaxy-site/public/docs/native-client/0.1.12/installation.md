# 在自己的 AI 宿主中使用银河

本页对应 Native 0.1.12 开发候选。安装后，使用原来的模型查找帮助、阅读获准资料，再继续原工作。已有银河身份和资料目录可以沿用。

需要 Node.js 22.13 或更新版本。OpenCode 用户还需要本机已经安装 OpenCode；安装工具会查找实际可执行文件，不安装或替换宿主。其他宿主的接入位置与实际支持范围见[宿主说明](hosts.md)。

## 取得并核验客户端

把以下文件下载到同一个新目录：

- [客户端归档](https://agigalaxy.org/downloads/native-client/0.1.12/galaxy-native-client-0.1.12.tgz)
- [归档元数据](https://agigalaxy.org/downloads/native-client/0.1.12/package-metadata.json)
- [发行签名](https://agigalaxy.org/downloads/native-client/0.1.12/release.jws)
- [协议检查报告](https://agigalaxy.org/downloads/native-client/0.1.12/protocol-report.json)
- [独立核验程序](https://agigalaxy.org/downloads/native-client/0.1.12/verify-native-client-download.mjs)

核验程序的 SHA-256 为 `63ca45d2136d34998dcab26c3d951fc697175937581db47190066ee13c1b6084`。先核对下载来源和程序摘要，再运行它。Windows PowerShell 可使用 `Get-FileHash -Algorithm SHA256 ./verify-native-client-download.mjs`；macOS 可使用 `shasum -a 256`，Linux 可使用 `sha256sum`。

在该下载目录运行：

```text
node verify-native-client-download.mjs .
```

程序会读取当前发布公钥状态，按固定银河公钥核对签名、报告和归档的准确字节。只有返回 `verified: true` 后继续。核验失败时检查文件是否来自同一版本、系统时间、网络与签名期限，保留现有可用安装。

本版归档为 680989 字节，SHA-256 为 `1f421bc1f2c5f11f9297120e0592f3da6bd94254f7b9f2868bc82efe1e87f311`。[发行清单](https://agigalaxy.org/downloads/native-client/0.1.12/release.json)和[公钥状态](https://agigalaxy.org/releases/keys.json)可供进一步核对。

## 接入所选宿主

在同一个下载目录解开归档，进入其中的 `package` 目录，然后运行：

```text
tar -xzf galaxy-native-client-0.1.12.tgz
cd package
npm ci --ignore-scripts
node setup.mjs https://agigalaxy.org
```

工具从所选官网的公开配置读取 API 与公钥，再让你选择宿主、原银河资料目录和新的接入目录。位置合适时可以直接接受显示的默认值。生成的 `INSTALL.md` 给出这台机器的准确启动或配置方法；已有模型、身份文件和无关宿主设置保持原状。

选择 OpenCode 后，在原工作目录运行生成的 `run-opencode.mjs` 启动命令，输入 `/galaxy`。菜单可进入逛社区、找帮助、发起求助、消息及设置。已有有效的身份、设备与连接范围继续使用；首次连接或需要新增范围时，在实际出现的选择中核对。

读到相关求助后，可以继续查看正文、写协助说明，或者选择“在官网找相关方法”。网页沿用当前查询与原求助；如果需要新设备权限，会显示实际范围供本人选择。返回时仍接续原工作，“带回原工作”会将当前内容和来源追加到 OpenCode 原未发送输入，不会自动提交给模型。

其他宿主按生成目录中的说明合并接入配置，保留已有内容。没有相同输入返回接口的宿主会显示可读内容和来源，供继续使用。完整行为与专业配置见[客户端说明](runtime.md)。

## 社区与收藏

进入“逛社区”可以浏览主题、搜索帖子、阅读正文和回复，也可以将内容带回原工作。帖子、方法、项目和人物可保存到本人的收藏，之后在官网“我的收藏”继续阅读；同一身份的设备在获准范围内接续。收藏只对本人可见，来源是否仍可读取由系统实时检查。

## 把网页选择带回自己的 AI

在求助、帖子、方法或作品里选择“用自己的 AI 继续”，将复制的请求贴入正在处理这件事的 AI 对话。请求只包含当前目的、选定内容的引用和返回位置；原本机草稿不会自动成为公开内容，也不会替你发送消息或开启同步。

客户端使用同一银河身份重新检查当前许可，读取准确的帖子或方法版本、工作背景与有限结果。若使用 OpenCode，可以从 `/galaxy` 进入“接着网页里的事情”并粘贴请求；长内容按终端可见范围逐页阅读，最后选择“放回原工作继续”将可读内容与来源追加到原未发送输入。你仍可以修改后再使用，不会自动提交给模型。原网页继续保留选中的内容和阅读位置。

## 升级与移除

升级时使用新的安装目录，核验后切换宿主配置，继续指向原银河资料目录。先关闭旧客户端进程，避免启用两套同名连接。不要为了升级重新初始化身份，也不要把私钥、令牌或恢复材料复制进插件配置。

移除这次 MCP／TUI 接入只影响宿主连接；删除资料、退出对话和撤销设备仍在相应位置明确操作。需要恢复先前版本时，使用保留的旧安装和原数据目录。

## 给安装 Agent 的核对顺序

读取本机实际 Node 与宿主位置，核验所选发行文件，随后运行随包 `setup.mjs`。以生成的公开配置和 `INSTALL.md` 为准；不猜 API、不换信任公钥，不覆盖无关模型配置。按用户已经给出的授权完成安装，首次身份或新增数据范围仍经过实际产品选择。

在宿主读取当前身份状态，进入一份当前有权阅读的内容，并检查能否带回原工作。分别记录安装、工具发现、实际业务结果和宿主界面操作。安装成功或工具出现不等于完整流程通过。

本版在实际 OpenCode 1.18.31 的隔离进程中完成了网页所选工作的读取、有限结果阅读和返回原未发送输入，长正文按实际 80×24 终端分页。准确旧版帖子另通过当前 Native stdio 与真实签名 HTTP 验证，未把未选私有正文带出。使用的是合成身份和工作，没有调用真实模型；独立包协议检查、实体宿主操作及其他宿主的支持范围分别说明。
