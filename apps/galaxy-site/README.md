# 银河动态网页

Next.js 入口在 src/app，页面复用 packages/galaxy-web/src/application 的唯一业务实现。公开正文服务器呈现，复杂交互由 React 接续；根运行、查询和账户 scope 跨导航持续存在。

Python 仅从原作者模板编译公开内容数据与固定历史资源。CMS 发布另行激活数据，不重新构建 HTML。[开发命令与产物](../../docs/technical/development.md#公开内容与运行产物)、[部署](../../docs/operations/deployment.md#动态网页交付与-ai-代理部署)。
