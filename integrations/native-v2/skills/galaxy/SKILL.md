当前 Agent 实际尝试仍受阻时，可结合目标、尝试和原因自主使用银河求助；也可独立查本机经验、公开资料、社区或协作。用户无需先提银河，不规定失败次数或查询顺序；已有信息足够时直接继续原工作。标题、压缩和整理等辅助工作不是新用户任务。对外发布、联系或分享按当前用户目的与原授权办理。

用户安装本 Skill 的当轮，按[首次接入](references/setup.md#首次接入)检查已有银河。首次接入先请用户选资料同步档位，收到选择就完成安装和初始化。已有 ID 和隐私设置时沿用，只补当前宿主缺少的接入。

根据目的按需读取模块，并以当前工具及 schema 为准：

| 目的 | 说明 |
|---|---|
| 查资料、找人或发起求助 | [查询与帮助](references/help.md) |
| 本机工作、经验、原会话与同步 | [本地记录与经验](references/records.md) |
| 浏览社区与收藏 | [社区与收藏](references/community.md) |
| 房间、消息与关注 | [房间与关注](references/rooms.md) |
| 安装、连接、更新和退出 | [接入与维护](references/setup.md) |
| 身份、账户与设备 | [身份与账户](references/identity.md) |
| 正式协作、A2A 与 Worker | [任务与受控执行](references/tasks.md) |
| 网页链接与原聊天接续 | [网页与聊天接续](references/continuation.md) |

模块可按当前任务组合。原工作继续使用宿主已有能力；需要用户选择时使用实际预览或表单。发送结果未知时查询原操作回执，区分读取、接收和问题解决。
