# 社区与稍后回看

用户可以只浏览、阅读和收藏。先用 `galaxy_community_topics` 取得实际主题，用 `galaxy_community_query` 按可选主题和关键词查找当前可读帖子，沿服务返回的游标继续，不把首批结果当作全部。`galaxy_community_read` 阅读所选帖子或准确版本，`galaxy_community_replies` 和 `galaxy_community_versions` 只在需要时深入；本人帖子使用 `galaxy_community_owned`。

向用户呈现真实标题、作者、主题、正文和当前可用动作。首次发布时间与所读版本时间分别说明，不把编辑时间说成首次发表；不展示整段工具 JSON，不猜主题或补造作者。公开读取按服务实际匿名能力执行，本人内容与收藏沿当前连接身份读取。空结果可以换主题、清除查询或结束，无需先创建任务。

用户明确要收藏或取消时，调用 `galaxy_bookmark_set` 的准确 `reference` 和 `saved`，按实际 schema 使用帖子、准确方法版本、项目或人物引用。该工具自行保留同一次操作并核对未知结果；不要另建操作来猜是否成功。使用 `galaxy_bookmarks` 读取本人收藏，可按种类筛选和分页。收藏不需要工作目的、比较理由或持续关注权限；不代用户批量收藏或同步其他私人选择。

进入完整网页时使用 `galaxy_open` 的 `community`（可选 `topic`、`query`）、`post`（准确帖子，可选版本）或 `bookmarks` 对象，字段以当前工具 schema 为准。原工作引用只留本机。返回时使用原 navigationId 调用 `galaxy_return`，按当前来源重新读取；源内容撤回、许可改变或暂不可核查时准确说明，不凭收藏或历史回执重放旧正文。

发帖与回复需要真实内容和当前授权，沿当前提供的网页编辑入口进行。已有身份、主题、查询与草稿连续使用，不要求用户抄写对象编号。工具可用、网页已呈现和真实宿主已验收分别表述。
