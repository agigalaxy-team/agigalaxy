# 接入与维护

用户安装 Skill、请求接入或维护时使用本说明。已有工具可用时直接处理原任务，公开资料可直接查阅。

## 首次接入

识别当前宿主、系统和已有安装。可用时读取一次 `galaxy_native_status` 或 `galaxy_integration_status`，也可用已安装客户端的 `galaxy status --json` 检查本机。已有身份和隐私设置就沿用，已接入的宿主直接使用。读取失败时先查明状态。

首次接入在下载和安装客户端之前，请用户选一个资料同步档位。使用下方的[银河呈现方式](#银河呈现方式)，标题为「首次接入」，说明正在选择资料同步范围。用户只需选择 1–4 中的一档。支持原生选择控件的界面可直接点选，聊天表格和纯文字渠道可回复编号。

| 编号 | 名称和含义 | 安装参数值 |
| --- | --- | --- |
| 1 | 只存本机（推荐）。工作资料留在这台设备。 | `local-only` |
| 2 | 履历概况。可同步所选工作的类型、角色、时间、结果和主要环境版本。 | `history-overview` |
| 3 | 选定工作内容。在履历概况上增加所选工作的具体说明、过程摘要和获准材料。 | `work-content` |
| 4 | 完整会话可选。工作资料范围同第 3 档，只有另外选定的会话才可同步原文。 | `conversation-archive` |

向用户呈现名称和含义，安装参数留给 Agent。第 1 档为默认和推荐，以实际收到的选择开始安装。这个选择同时确认本次安装和初始化，只设置将来允许的范围。实际同步还需选择目标和资料，凭据始终排除。

Agent 复用可用客户端，或从[银河官网下载](https://agigalaxy.org/downloads/)选择适合当前环境的正式包并[核验发行](https://agigalaxy.org/downloads/verification/)。运行包内的 `galaxy setup https://agigalaxy.org --host <当前宿主> --upload-privacy <参数值> --json`，将所选档位交给初始化。使用现有 `install` 接入入口时同样传入 `--upload-privacy`。第 1 档是资料范围，正常官网接入仍用官网地址。另有明确的离线使用要求时，使用安装命令的 `--local-only`。已有身份继续沿用保存的档位。

## 银河呈现方式

首次接入和安装回执都用「银河 / AGI GALAXY」署名。当前 Agent 根据界面提供的能力和空间排版。支持原生面板时，用带边框的品牌区和真实表格。品牌区参考银河官网的近白粉底 `#fff9fc`、浅粉描边 `#f3e9ef` 和深色字标 `#202735`，少量重点用官网粉 `#b54976`。正文与表格沿用宿主的常规文字配色。支持聊天表格时，使用聊天原生表格。纯文字渠道用短标题和逐项文字表达。标题、留白和列宽可按实际界面调整。

## 安装回执

用一行说明安装结果，接着呈现「功能检查」。有表格时使用「检查项、状态、实际结果」三列。通常包含本机身份、Agent 工具和银河服务。当前宿主有相应能力时可展示公开资料查询、本机经验检索和本机工作记录。回执只呈现安装和功能结果，资料同步档位、配置路径及诊断留在各自入口。

优先复用安装结果。当前对话可调用时，读取一次状态核对身份、工具和连接。公开资料查询和本机经验检索只有实际只读查询成功时才标「可用」，返回空列表仍是一次成功的读取。工作记录按已采集记录或宿主采集状态填写，配置成功可写「已配置」，有明确启用证据且未产生记录时才写「待首次记录」。部分结果未检查时可省略对应的可选项，主要状态缺少证据时写「未确认」。宿主配置成功但当前会话尚未加载工具时，根据实际宿主情况提示重开或重载。安装未完成时只补充明确的原因或下一步。

## 更新与使用

更新客户端、Skill 和模块时使用 `galaxy update --host <当前宿主>` 检查并应用新版，沿用原 ID 和资料；以实际正在响应 MCP 的运行版本为准；安装或配置已更新不等于旧常驻服务已切换。切换未完成时按结果处理。没有联网更新能力的旧客户端使用[一次性迁移入口](https://agigalaxy.org/docs/galaxy/getting-started/#升级退出与移除)；同版配置刷新用 `repair`。

接入范围是当前系统用户的当前宿主。需要账户功能时再办理关联，参见[身份与账户](identity.md)。实际同步时按[本地记录与经验](records.md)选择目标和资料范围。

共享本机服务按需启动后保持运行，多个宿主复用；关闭单个宿主不退出服务。`galaxy service stop` 退出、`start` 重新启用。连接存活不调用模型；可选事件钩子不可用时，普通 MCP 与 Skill 仍可使用。配置生成、工具发现、事件采集与实际宿主行为分别以结果为准。
