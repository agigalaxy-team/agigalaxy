# 首次接入

首次接入而且用户还没明确选档时，当前回复只展示下表并等待。可以用宿主选择控件，也可以发出编号列表后结束回复。推荐第 1 档，由用户提交选项。安装请求、推荐标识或命令权限均不算选择。

| 档位 | 允许范围 |
| --- | --- |
| 1 · 只存本机（推荐） | 工作资料留在本机 |
| 2 · 履历概况 | 所选工作的类型、角色、时间、结果及主要环境版本 |
| 3 · 选定工作内容 | 另含所选说明、过程摘要和材料 |
| 4 · 完整会话可选 | 同第 3 档，原会话还须另行选定 |

用户明确回复后，才打开[安装与回执](setup-install.md)，使用实际所选编号。用户未回答或取消时继续等待。

已有银河 MCP 时可先查 `galaxy_native_status`。已初始化并保存过同步范围的设备沿用原选择，缺组件时直接进入[补装](setup-install.md)。
