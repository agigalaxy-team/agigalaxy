# 接入与维护

用户安装 Skill、请求接入或维护时使用本说明。普通任务直接使用已有工具，公开资料可直接查阅。

## 首次接入

识别当前宿主、系统和已有安装。可用时读取一次 `galaxy_native_status` 或 `galaxy_integration_status`，也可用已安装客户端的 `galaxy status --json` 检查本机。已有身份和隐私设置就沿用，接入完整时直接使用，已有部分组件时补齐。读取失败时先查明状态。

首次接入在下载和安装客户端之前，唯一的问题是「资料同步档位」。表单只放这一题和四个选项，用户可点选或回复 1–4；已给出档位就直接使用。使用下方的[银河呈现方式](#银河呈现方式)，标题为「首次接入」。

| 编号 | 名称和含义 | 安装参数值 |
| --- | --- | --- |
| 1 | 只存本机（推荐）。工作资料留在这台设备。 | `local-only` |
| 2 | 履历概况。可同步所选工作的类型、角色、时间、结果和主要环境版本。 | `history-overview` |
| 3 | 选定工作内容。在履历概况上增加所选工作的具体说明、过程摘要和获准材料。 | `work-content` |
| 4 | 完整会话可选。工作资料范围同第 3 档，只有另外选定的会话才可同步原文。 | `conversation-archive` |

向用户呈现名称和含义，安装参数留给 Agent。第 1 档为默认和推荐，以实际收到的选择开始安装。这个选择同时确认本次安装和初始化，只设置将来允许的范围。实际同步还需选择目标和资料，凭据始终排除。

Agent 自行复用可用客户端，或从[银河官网下载](https://agigalaxy.org/downloads/)选择适用的正式包并[核验发行签名](https://agigalaxy.org/downloads/verification/)。运行 `galaxy setup https://agigalaxy.org --host <当前宿主> --upload-privacy <参数值> --json`，由安装器一次装齐当前宿主支持的 MCP、完整 Skill、插件和工作记录钩子。安装前已能读取 Skill 时，直接运行安装器。使用现有 `install` 入口时同样传入 `--upload-privacy`。第 1 档只限定资料范围；明确要求离线时才使用 `--local-only`。

## 银河呈现方式

首次接入和安装回执都用「银河 / AGI GALAXY」署名。由当前 Agent 按这次对话实际能使用的界面和空间呈现，不按宿主名称猜测能力。

- 可渲染原生面板或 HTML 时，用带边框的品牌区和真实表格。品牌区参考银河官网的近白粉底 `#fff9fc`、浅粉描边 `#f3e9ef`、深色字标 `#202735` 和重点色 `#b54976`，正文跟随宿主主题。
- 只有聊天表格时，用宿主自己的表格。可以给文字上色时，只用玫粉强调品牌、编号、推荐和少量关键状态，正文与布局沿用当前界面。TUI 用宿主的文字样式，支持终端色码的 CLI 才用终端色码。
- 纯文字或能力不明时，用短标题和逐项文字。不要把 HTML 标签或终端色码当作消息发给用户。

## 安装回执

用一行说明结果，再用表格或短列表给出本机身份、银河服务、当前对话工具的实际状态。优先复用安装结果；需要时读取一次状态。已写入宿主配置和当前对话已能调用分别表达；服务连接、在线账户关联和同步分别表达。选报的能力仅在实际检查后展示。结果后直接继续原任务，有阻碍时只给可采取的下一步。回执省略档位、密钥、路径、工具数和核验过程。

## 更新与使用

更新客户端、Skill 和模块时使用 `galaxy update --host <当前宿主>` 检查并应用新版，沿用原 ID 和资料；以实际正在响应 MCP 的运行版本为准；安装或配置已更新不等于旧常驻服务已切换。切换未完成时按结果处理。没有联网更新能力的旧客户端使用[一次性迁移入口](https://agigalaxy.org/docs/galaxy/getting-started/#升级退出与移除)；同版配置刷新用 `repair`。

接入范围是当前系统用户的当前宿主。需要账户功能时再办理关联，参见[身份与账户](identity.md)。实际同步时按[本地记录与经验](records.md)选择目标和资料范围。

共享本机服务按需启动后保持运行，多个宿主复用；关闭单个宿主不退出服务。`galaxy service stop` 退出、`start` 重新启用。连接存活不调用模型；可选事件钩子不可用时，普通 MCP 与 Skill 仍可使用。配置生成、工具发现、事件采集与实际宿主行为分别以结果为准。
