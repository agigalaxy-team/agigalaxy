# 接入与维护

用户安装 Skill、请求接入或维护时使用本说明。已有工具可用时直接处理原任务，公开资料可直接查阅。

## 首次接入

识别当前宿主、系统和已有安装。可用时读取一次 `galaxy_native_status` 或 `galaxy_integration_status`，也可用已安装客户端的 `galaxy status --json` 检查本机。已有身份和隐私设置就沿用，已接入的宿主直接使用。读取失败时先查明状态。

首次接入在下载和安装客户端之前，请用户选一个资料同步档位。用 **AGI GALAXY / 银河** 署名，写明「首次接入」和选择目的。由当前 Agent 按沟通界面的宽度和文本能力组织纯文本，用留白、编号或简短分隔线呈现层次。用户只需回复 1–4 中的一个数字。

| 编号 | 名称和含义 | 安装参数值 |
| --- | --- | --- |
| 1 | 只存本机（推荐）。工作资料留在这台设备。 | `local-only` |
| 2 | 同步概况。可同步所选工作的类型、时间和结果等基本信息。 | `history-overview` |
| 3 | 同步工作内容。还可同步所选工作的说明、摘要和材料。 | `work-content` |
| 4 | 可归档会话。还可单独选定会话，同步这些会话的原文。 | `conversation-archive` |

向用户呈现名称和含义，安装参数留给 Agent。只标记第 1 档为推荐，以实际收到的选择开始安装。这个选择同时确认本次安装和初始化。

Agent 复用可用客户端，或从[银河官网下载](https://agigalaxy.org/downloads/)选择适合当前环境的正式包并[核验发行](https://agigalaxy.org/downloads/verification/)。运行包内的 `galaxy setup https://agigalaxy.org --host <当前宿主> --upload-privacy <参数值> --json`，将所选档位交给初始化。使用现有 `install` 接入入口时同样传入 `--upload-privacy`。第 1 档是资料范围，正常官网接入仍用官网地址。另有明确的离线使用要求时，使用安装命令的 `--local-only`。已有身份继续沿用保存的档位。报告实际结果，宿主需要重载时按该宿主方式接续。

## 更新与使用

更新客户端、Skill 和模块时使用 `galaxy update --host <当前宿主>` 检查并应用新版，沿用原 ID 和资料；以实际正在响应 MCP 的运行版本为准；安装或配置已更新不等于旧常驻服务已切换。切换未完成时按结果处理。没有联网更新能力的旧客户端使用[一次性迁移入口](https://agigalaxy.org/docs/galaxy/getting-started/#升级退出与移除)；同版配置刷新用 `repair`。

接入范围是当前系统用户的当前宿主。需要账户功能时再办理关联，参见[身份与账户](identity.md)。实际同步时按[本地记录与经验](records.md)选择目标和资料范围。

共享本机服务按需启动后保持运行，多个宿主复用；关闭单个宿主不退出服务。`galaxy service stop` 退出、`start` 重新启用。连接存活不调用模型；可选事件钩子不可用时，普通 MCP 与 Skill 仍可使用。配置生成、工具发现、事件采集与实际宿主行为分别以结果为准。
