# 房间、摘要与用户 Agent

普通聊天独立成立，不自动建任务、履历或 Capsule。具体 Task 协作动作另读 [任务与受控执行](tasks.md)。先确认当前工具实际允许的房间与材料范围，再读取所需历史；不把别的私聊、私有摘要或全量原聊天搬进新房间。

## 历史、消息与摘要

沿原房间用当前可用的 `galaxy_chat_*` 读取消息和后续页，把真实回应带回原工作；未读取、失败和无新消息分别处理。后台通知只按宿主实际支持的接口进行。先呈现当前消息和可用回复，历史与个人摘要按问题深入取用。支持嵌入面板的宿主中，面板会自动读取消息页、保留本机回复草稿并查询未知发送结果；不支持的宿主由 Agent 使用普通工具读取和说明。精确 clientMessageId、hash、游标和授权范围由 Agent 与系统沿原引用处理，不要求用户填写技术表单。新的 respond 授权仍须本人选择；已有有效授权无需重复确认普通发送。

房间完整共享历史、背景摘要、关键消息并存。消息 ID、版本和来源权限来自当前工具结果。用户已读、Agent 已处理与对端接受分别表述；阅读不等于成功复用，最终解决者不自动获得其他参与者的贡献。

普通发送、附件或分享结果未知时保存原定位，先查询原 ID/hash 回执；当前房间读失败不能直接当原发送 absent。对 `galaxy_chat_send`，可用 `galaxy_chat_pending_sends({roomId})` 查当前银河身份、服务与房间下本机保留的未决 `clientMessageId` 和 `requestHash`，再用 `galaxy_chat_message_status` 核对同一条发送。定位在发送前保存，已确认接收的条目不再保留在未决列表。这里不保存消息正文或授权供重发；宿主退出后只能沿原定位核对，不能声称原草稿已恢复。若仍持有完全相同的原内容，是否继续由用户及当前 Agent 根据真实回执决定；不自动换编号重发。退房、撤权、来源失效后的最小历史 receipt 不授予正文访问或新发送权限。附件/复制文件的期限和批准范围以各自当前授权为准，不把临时来源到期与独立批准副本混为一个状态。

`galaxy_summary_local_save` 默认只在本机保存用户模型或用户编写的个人摘要，不产生模型调用。私有云同步是独立 opt-in，以同步选择限制房间范围；不套用到 Choice 或其他类别，不等于房间分享或全量上下文上传。原 unknown 版本先对账，关闭新同步不抹掉原回执，也不等于已删云副本。冲突保留两版供明确合并，不能静默覆盖。

房间分享另选具体片段和当前可读来源版本，明确接收范围。私人摘要更新不会自动覆盖已分享版本。来源失效后重新核对当前可读部分，撤回正文、外部消息清理与物理归档删除分别记录，未知清理不称永久删除。取得历史接受回执不能判断别人读过或仍能读取。

本机原会话与房间摘要分开，采集与管理见[本地记录](records.md)。

## 可选 Agent 权限与持续关注

通过 `galaxy_chat_agent_grants` 检查当前连接授权，新增权限用 grant，撤销用 revoke。read、draft、respond 与主要响应者各按实际授予范围；宿主有发送工具不等于已获银河房间 respond 授权，已有同房间有效授权无需重复确认。权限存在不等于宿主模型已运行。用户未选择参与或缺后台能力时继续原聊天，不自行补后台程序。

按用户当前目的使用实际可用的 `galaxy_watch_start/check/status/ack/pause/resume/stop`，不要求先建专用子会话或进菜单。新关注使用当前房间、Agent grant 和用途，期限按实际委托及工具 schema 填写；程序返回的 nextCheckAt/退避用于变化读取，不能替代 Agent 判断工作何时完成。处理完对应材料后使用原 workId ACK Agent 游标，不写人类已读；房间 read/draft/respond 沿当前 grant 执行。

`galaxy_watch_host_capabilities/activate/reconcile` 是已有专用分析执行的可选兼容能力，不是普通Agent读取、参与或持续工作的前置步骤。只在该用途实际需要时使用；旧只读分析不自动扩大为其他任务。原执行结果未知时查询原thread/turn/work，不另开模型猜结果；没有该driver仍可用完整普通MCP工具处理。

暂停先停银河新工作并撤销精确 grant，再按宿主实际能力取消在途子会话；取消请求、确认终止和未知分别报告。恢复使用 `galaxy_watch_resume` 选择新当前 grant 与期限，不复用旧 binding。结束或撤销调用 stop，并核对宿主实际停止；stdio/宿主关闭后银河不会在云端接替模型。关闭界面不等于业务取消，暂停 HelpSession 也不等于暂停 Watch。

## 提醒与前台回退

仅在实际工具存在且用户明确启用时使用本机系统提醒。`galaxy_host_notifications_status` 读取状态不启动 helper；`galaxy_host_notifications_enable` 的本次选择不代表系统权限已获准。支持的 macOS permission 工具必须每次独立真实选择，不自动提示系统授权；拒绝后保持拒绝。禁用/退出撤回仍由本进程持有的提醒，不能称所有设备或系统副本已删除。

系统接受 Notify/add 不等于已展示、点击或人类已读。静音仅影响打扰，不取消协作责任；Agent cursor 仍独立。来源撤回后不继续显示旧私文，离线重连不重刷未知旧提示。通道不可用、系统权限未获准或展示不确定时，保留当前允许的前台收件箱与稳定对象入口，不自动安装 helper 或改变系统安全设置。
