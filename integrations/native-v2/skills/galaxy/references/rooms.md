# 房间、摘要与用户 Agent

普通聊天独立成立，不自动建任务、履历或 Capsule。具体 Task 协作动作另读 [任务与受控执行](tasks.md)。先确认当前工具实际允许的房间与材料范围，再读取所需历史；不把别的私聊、私有摘要或全量原聊天搬进新房间。

## 历史、消息与摘要

先呈现当前消息和可用回复，历史与个人摘要按问题深入取用。支持当前 Apps 源码的宿主中，面板会自动读取消息页、保留本机回复草稿并查询未知发送结果；不支持的宿主由 Agent 使用普通工具读取和说明。精确 clientMessageId、hash、游标和授权范围由 Agent 与系统沿原引用处理，不要求用户填写技术表单。新的 respond 授权仍须本人选择；已有有效授权无需重复确认普通发送。

房间完整共享历史、背景摘要、关键消息并存。消息 ID、版本和来源权限来自当前工具结果。用户已读、Agent 已处理与对端接受分别表述；阅读不等于成功复用，最终解决者不自动获得其他参与者的贡献。

普通发送、附件或分享结果未知时保存原定位，先查询原 ID/hash 回执；当前房间读失败不能直接当原发送 absent。退房、撤权、来源失效后的最小历史 receipt 不授予正文访问或新发送权限。附件/复制文件的期限和批准范围以各自当前授权为准，不把临时来源到期与独立批准副本混为一个状态。

`galaxy_summary_local_save` 默认只在本机保存用户模型或用户编写的个人摘要，不产生模型调用。私有云同步是独立 opt-in，以同步选择限制房间范围；不套用到 Choice 或其他类别，不等于房间分享或全量上下文上传。原 unknown 版本先对账，关闭新同步不抹掉原回执，也不等于已删云副本。冲突保留两版供明确合并，不能静默覆盖。

房间分享另选具体片段和当前可读来源版本，明确接收范围。私人摘要更新不会自动覆盖已分享版本。来源失效后重新核对当前可读部分，撤回正文、外部消息清理与物理归档删除分别记录，未知清理不称永久删除。取得历史接受回执不能判断别人读过或仍能读取。

## 可选 Agent 权限与持续关注

通过 `galaxy_chat_agent_grants` 检查当前连接授权，新增权限用 grant，撤销用 revoke。read、draft、respond 与主要响应者各按实际授予范围；权限存在不等于宿主模型已运行。用户未选择参与或缺后台能力时继续原聊天，不自行补后台程序。

用户选定房间、目的、当前 Agent grant 和结束条件后使用 `galaxy_watch_start`。默认按需；普通关注建议 24 小时，长期需明确选择。宿主按实际 nextCheckAt 调度 `galaxy_watch_check`；常规 15 分钟只查变化，错误按返回的退避执行，不把轮询当模型会话。无变化零模型调用，有变化才由用户 Agent 在当前授权范围处理。真实完成后才用原 workId ACK Agent 游标，不写人类已读。

有 `galaxy_watch_host_capabilities` 时先核当前可信配置与有效 reader 限制；能力检查不创建模型 turn。用户明确选择配置的宿主和模型后才用 `galaxy_watch_host_activate`；不能用 CLI 存在、模型列表或协议替身测试宣称实际模型运行。未知宿主工作先用 `galaxy_watch_host_reconcile` 查原 thread/turn/work，不另开推理猜结果。没有可用 driver 时保留前台方式。

暂停先停银河新工作并撤销精确 grant，再按宿主实际能力取消在途子会话；取消请求、确认终止和未知分别报告。恢复使用 `galaxy_watch_resume` 选择新当前 grant 与期限，不复用旧 binding。结束或撤销调用 stop，并核对宿主实际停止；stdio/宿主关闭后银河不会在云端接替模型。关闭界面不等于业务取消，暂停 HelpSession 也不等于暂停 Watch。

## 提醒与前台回退

仅在实际工具存在且用户明确启用时使用本机系统提醒。`galaxy_host_notifications_status` 读取状态不启动 helper；`galaxy_host_notifications_enable` 的本次选择不代表系统权限已获准。支持的 macOS permission 工具必须每次独立真实选择，不自动提示系统授权；拒绝后保持拒绝。禁用/退出撤回仍由本进程持有的提醒，不能称所有设备或系统副本已删除。

系统接受 Notify/add 不等于已展示、点击或人类已读。静音仅影响打扰，不取消协作责任；Agent cursor 仍独立。来源撤回后不继续显示旧私文，离线重连不重刷未知旧提示。通道不可用、系统权限未获准或展示不确定时，保留当前允许的前台收件箱与稳定对象入口，不自动安装 helper 或改变系统安全设置。
