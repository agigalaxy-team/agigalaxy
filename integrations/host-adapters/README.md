本主题现行要求：[AI宿主、客户端与命令界面](../../../../../02-architecture/current/CLIENT_EXPERIENCE.md)；全产品交互遵循[体验规则](../../../../../02-architecture/current/EXPERIENCE_RULES.md)。按当前问题返回可读结果；完整背景按权限调用，界面按用途精炼。

共享 Native 的工作面板按目的显示帮助、消息、Worker 输入和实际输出，使用同一业务含义与稳定网页深链，详见[Native 客户端](../../docs/native-client-v2.md)。

OpenCode stable 当前源码的 `/galaxy` 从“找帮助、发起求助、消息、我的与设置、回到原工作”直接进入。打开不会创建身份或连接；本机身份准备和连接分别使用实际原生选择，保留后端原五层与准确连接预览。完整连接请求只在有目的的来源与诊断里查看，不要求用户输入确认口令。

宿主可以向 `createGalaxyAdapter` 或 `createConfiguredGalaxyAdapter` 提供 `nativeTools:{call(name,args)}` 和可选 `readWorkContext`。这是宿主已选的前台 Native 工具桥，不创建账号、模型或连接。提供后可读取当前帮助与消息，沿既有有效 respond 权限回复；原消息确认未知时查询同一条消息，网页返回沿原导航接续。身份、连接变化使旧内容失效，未提供桥接时如实保留原聊天和已配置网页路径。

当前已核验 stable Dialog 合同、实际 Native MCP、签名 HTTP/PGlite 与消息恢复；聊天传输和账号资格是显式合成夹具。已在本机 OpenCode 1.18.31 的实际进程和 TUI 插件 API 中检查目的首屏、未配置提示、按需语言、返回及停用后重新进入，隔离身份目录保持不变。这个运行没有提交模型提示，也不证明已连接的实体服务、真人桌面效果或其他独立 host adapter。冻结发行和已安装配置未由本次源码变化更新。

有前台 Native 工具桥时，“我的与设置”读取该桥的当前稳定身份；不会另行读取或创建宿主默认目录的第二个身份。身份、资料、方法、协作及所选设备操作使用原生 Dialog 的实际选择，冻结内容和既有后端确认仍保留。日常预览显示内容与必要范围；完整协议仅在“来源与完整内容”展开。既有查询、只读结果及已授权的准确恢复不因此增加新的审批步骤。

能力边界：仅提供 Native 工具桥时还没有连接独立 v1 节点写入及删除控制器；此批没有自动接入第二个身份或真实账户。旧控制器没有按原 Case 列举 Evidence 的读取能力，普通交付可不附加材料，并可使用已掌握的原材料引用；不会从搜索 Proof 猜 Evidence 归属。导出服务声明但当前控制器没有列表能力的来源类型仍说明缺少读取接续，保留已有引用入口。建设者完整登记、兼容套件报告和协议来源保留其必要专业输入。Native 桥仍由宿主明确提供，冻结发行、已安装配置、其他独立宿主及真实用户模型链路未由源码或合同镜像测试证明已完成。

前台 Native 桥的“找帮助”现可直接进入“寻找同行”，按当前工作带入方向或选择本人已有项目。项目介绍与当前可读经历直接阅读，返回进入该项目的相关动作，不再强制重读介绍。整体工作是否另有结论与一次结果的“部分完成”分开表述；内部枚举与精确来源保留在来源详情。发起联系使用所选项目的准确来源，正文与用途保留在真实本机选择页；没有手填项目、主体或操作编号。

发送联系、对方接受和新的聊天回复权限分别使用各自的实际 Native 选择。一次普通交流不会建立求助、参与或交付承诺；接受后只进入服务真实返回的同一个普通房间。当前消息在仍打开的阅读 Alert 自动更新，输入或其他选择开始后停止该阅读更新；失去当前许可则收起旧内容。已有 respond 权限直接沿用，没有时才展示该真实房间名称和本次一小时范围。内容授权的截止时间与本机选择页时限分别显示，原操作恢复不能把未批准的 prepared 当成已批准操作。
